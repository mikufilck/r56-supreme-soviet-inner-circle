## 2. 全线视觉母题：**「一份文件，和照着它做的部队」**

⭐⭐ 本线讲的不是「他打了什么仗」，而是「**一份想法怎么变成全军的令**」——
所以六张图的母题是**「制式的东西」**（纸 / 装备 / 条令），**不是战场、不是指挥部、不是人像**。

| 母题 | 出现位置 | 含义 |
| --- | --- | --- |
| ⭐⭐ **制式的纸**（讲义 / 指示 / 条令） | **#1 #4 #6** | 构想变成文字的**三个阶段**：讲义 → 指示 → 条令 |
| ⭐⭐⭐ **「排成一套」的装备**（肩章 / 成套装备 / 伞与履带） | **#1 #2 #3** | **军队被【编成】的样子** —— 这是本线的主角 |
| ⭐⭐⭐ **层 / 折**（三道折痕 / 四条横带） | **#4 #5** | ⭐ **「纵深」** —— 本线的核心词，但它**画的是"层次"，不是地图** |
| ⭐ **旧的与新的并置** | **#2 #6** | 「改造」这件事，只能靠对比看出来（散乱 vs 成套；磨痕的钢盔 vs 新书） |

### 2.1 ⭐⭐ 一句话记法

> **别人画的是「他在战场上做了什么」，本线画的是「纸上的东西什么时候变成了全军的令」。**
