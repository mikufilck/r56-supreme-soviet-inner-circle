## 2. 全线视觉母题：**「卡片与名册」**

> ⭐ **他是 22 人里唯一管过「二百五十万张卡片」的人** —— 母题就从这里来。

**六个意象是同一件东西的六种形态**：

```text
一只抽屉 → 一本册子 → 一张长桌 → 一页记录 → 一块黑板 → 一本册子（合上）
  收          存          用          错          造          定
```

⭐⭐ **首尾同轴（给美术的一句话）**：**根**画的是**一只装着别人的名字的抽屉**；
**结局**画的是**一本立在桌上的册子** —— **同一件东西，从「被保管」变成「被照着办」。**

### 2.1 🚩🚩 与其他两条线的母题区分（判据 A：**避重要去隐喻**）

| 线 | 母题 | 画面里出现的是 |
| --- | --- | --- |
| 施利亚普尼科夫（Idx 13） | **制度的物证** | 账本 / 名单 / 计划表 / 抽屉（**文本**） |
| 彼得·斯米尔诺夫（Idx 19） | **一间机关里的物证** | 门牌 / 海图 / 报纸 / 长桌 / 盖章的决议（**文本**） |
| **本线** | **卡片与名册** | **卡片本身的物理形态**：一张硬卡片 · 一个拉开的卡片抽屉 · 一排卡片盒 |

📌 **一句话区分**：**他们画的是「纸上写着什么」，本线画的是「卡片本身长什么样」。**

## 3. 🚩🚩 色调纪律（`docs/23` **判据 G**）

> **色调只能来自「画面里那个东西本身的颜色」。**

| 允许的颜色 | 来自哪个物体 |
| --- | --- |
| **木色 / 深褐** | 卡片抽屉 · 长桌 · 椅子 · 课桌 |
| **纸白 / 米黄** | 卡片 · 册页 · 地图 · 记录页 |
| **红**（**只允许一处**） | A2 的**印章印泥** —— 其余五张**一律不许有红** |
| **灰蓝**（**只允许一处**） | A4 的**机库**（机身用中性灰，**不要上军用涂装**） |
| **深绿** | A5 的**黑板**（**深绿，不是彩绿**） |
| **黑** | A3 的**电话**（+ 必要的线条） |

🚩 **自检法**：把画面里的物体逐个念一遍 —— 如果那个色**不属于其中任何一个物体**，它就超标了。
⛔ **禁止**：整张图上色 / 霓虹 / 高饱和 / 彩色渐层 / 光晕。

## 4. ⛔ 全线硬性禁区（**一条都不许破**）

| # | 禁区 | 原因 |
| --- | --- | --- |
| 1 | **不画人** | 全线一律不画；照已实装 20 条线的惯例 |
| 2 | **不画枪 / 刑场 / 铁窗** | 他是**加害者**一侧；画出来会变成「清洗」的暗示 |
| 3 | **不画列宁格勒**（斯莫尔尼宫 / 州委大楼 / 带枪的队伍） | 🔴 **1949 列宁格勒案件 —— 受害者是沃兹涅先斯基（Idx 18，本 mod 已实装的本人）** |
| 4 | **不画集中营 / 被划掉的名字 / 撕碎的名单** | 会被读成清洗；本线一个节点都不碰这个题 |
| 5 | **不画 1937 年** | 同上 |
| 6 | **不画德国 / 火箭发射 / 蘑菇云** | 火箭是**备选**未采纳；核是别的线且涉核 |
| 7 | **不画工厂车间 / 车床 / 炼钢炉** | 那是**斯米尔加（Idx 10）/ 沃兹涅先斯基（Idx 18）/ 图哈切夫斯基（Idx 17）**的领域 |
| 8 | **不画军舰 / 海图** | 那是**彼得·斯米尔诺夫（Idx 19）**的 |
| 9 | **不画镰刀锤子 + 人像组合** | 涉个人崇拜；本线不碰 |
| 10 | **A1 不要画「盖章的动作」** | 那是 A2 的意象；A1 只画**卡片本身** |
| 11 | **E1 的册子封面必须无字** | 有字就变成「文件特写」，丢掉「立在桌上」的体积感 |
| 12 | **A5 的黑板只画提纲线条** | **不许出现任何可辨认的西里尔/中文字**（会与世界线产生歧义） |
