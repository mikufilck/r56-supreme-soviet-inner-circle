## 1. 要出的图（共 5 张）

> ✅ **本批的特殊之处：他是一个【车工】（车床工）**。整条线的视觉母题因此是
> **「连接」** —— 他一辈子干的事就是**把散落的部件接成一台能运转的机器**（`docs/41` §5.1）。
> ⚠️ **五条文案里只有 1 条是中文原文**（A2），其余 4 条是俄文维基的记述（已去引号）。
> 逐条出处见 `docs/42` §5。

### ⚠️ 整条线的视觉注意事项

1. **母题只有一件事：接线。** 本批的关键词是：
   **走出营房的队列 / 从四方汇向中心的线 / 交错的轨道与道岔 / 伸向地平线的路面 / 车床与卡盘**。
   与已完成批次明确区分开：

   | 批次 | 母题 |
   | --- | --- |
   | 李可夫（`docs/31`） | 工业、机构、供给线 |
   | 季诺维也夫（`docs/34`） | 国际、会场、东方人群 |
   | 加米涅夫（`docs/37`） | 手稿、档案、书与印刷 |
   | 斯米尔诺夫（`docs/40`） | 河、铁轨、雪原、界线 |
   | **谢列布里亚科夫（本批）** | **营房、汇聚的线、道岔、公路、车床** |

   🚩 **与斯米尔诺夫那批最容易混的一点**：他那张是**河上的铁路桥**（**地形**，一列队伍在过河）；
   本批的 A3 是**道岔与信号楼**（**动作**，一堆线在这里被接起来）。
   **一个是「过河」，一个是「并轨」** —— 出图时请把这两张摆在一起看，别画成同一种构图。

2. **五张是一条「从脚到手」的链，不是一个横排的系列** —— 顺序本身有意义：
   **一双走出营房的靴子（1917） → 一张从四方汇向中心的网（1920） →
   一堆被接起来的轨道（1921） → 一条伸向地平线的路（1931） → 一双手在车床前（回到根）**。
   出图时请**按顺序看一遍**：**从「群体」逐步收窄到「一双手」**，色彩从冷到暖。

3. **E1 是结尾，构图应最饱满**（照布哈林 E1 / 李可夫 E1 / 加米涅夫 E1 / 斯米尔诺夫 E1 的处理）——
   它是全线的最后一个节点，**四个前置全完成**后才开。

4. 🚩 **画面里不要出现可辨认的文字**（`docs/24` §1）——
   路牌、票签、箱标上可以有条纹与色块，但**不要写出可辨认的字母或汉字**。

5. ✅ **本批没有互斥项、没有成对图**（本线是单线）—— 5 张是一体的。

6. ⚠️ **不要画人脸、不要画人物肖像**（本批走苏联国策图标式）——
   需要「人」时用**队列 / 背影 / 手 / 剪影**，不要五官。

## 2. 整条线的视觉小结

| 顺 | 图 | 介质 | 主体 | 色调 |
| --- | --- | --- | --- | --- |
| A1 | 科斯特罗马的驻军 | 雪地 / 营门 | **一群靴子往外走** | 冷蓝灰 |
| A2 | 党中央书记处 | 桌面 / 网络 | **四方汇向一点** | 暗红 + 冷灰 |
| A3 | 交通人民委员部 | 铁轨 / 道岔 | **几股并成一股** | 铁锈褐 + 烟灰 |
| A4 | 公路与汽车运输总局 | 公路 | **一条路伸向天际** | 土黄 + 淡蓝 |
| E1 | 天才的工人 | 车床 | **一双手 + 一件刚车好的活** | 暖金属 + 冷阴影 |

**一条链的三个变化**：
1. **视点**：群体（A1）→ 关系（A2）→ 设施（A3/A4）→ 双手（E1）
2. **色温**：冷 → 暖（一路加温）
3. **「线」的形态**：脚印（A1，尚未成形）→ 网（A2）→ 轨（A3）→ 路（A4）→ 成品（E1）
