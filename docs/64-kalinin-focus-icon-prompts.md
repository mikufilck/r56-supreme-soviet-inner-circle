## 2. 全线视觉母题：**「够得着」的物证**

⭐⭐ 本线讲的不是「他做了什么大事」，而是「**国家找不找得到**」——
所以六张图的母题是**「一张被翻开的纸」与「一道被走过的门」**，
**不是主席台、不是勋章、不是办公室**。

| 母题 | 出现位置 | 含义 |
| --- | --- | --- |
| ⭐⭐ **一张被翻开的纸**（课本 / 信 / 表决单 / 文件） | **#1 #2 #4 #5** | **国家与人的接触，全发生在纸上** —— 但不写可辨识的字 |
| ⭐⭐ **一道道 / 一扇门**（圆心 / 门缝 / 门槛） | **#3 #4 #6** | **够得着 / 够不着** —— #3 是「谁都能进来」，#4 是「只有一条缝」，#6 是「已经被人踩亮了」 |
| ⭐ **平凡人的背影**（工帽 / 头巾，**不画正面脸**） | **#2 #6** | **主角是「来找国家的人」，不是他本人** |
| ⭐ **麦穗**（唯一一次庄稼的记号） | **#1** | 与入口图标 `docs/28` §7 的「**麦穗**（农民出身）」呼应 —— ⚠️ **呼应不是照搬** |

> 🚩 **与三条已实装线的区分（本线排掉 0 人，21 人全能同席，所以必须写死）**：
> | 线 | 他的母题 | 本线 |
> | --- | --- | --- |
> | **施利亚普尼科夫（Idx 13）** | **「制度的物证」** —— 账本 / 名单 / 计划表 / 抽屉 | ⚠️ **最近**！→ 本线的纸**不是制度表格，是「人写给国家的东西」**（课本 / 信 / 表决单）→ **不画格子表、不画计划表、不画抽屉** |
> | **托姆斯基（Idx 11）** | **工会主席的会旗与讲台** | ⛔ **本线不画旗、不画讲台** |
> | **里亚京（Idx 12）** | 一份杂志 / 一张报纸 / 一叠手抄稿 | ⚠️ 也是「纸」→ 本线**不画印刷机、不画报纸版式、不画摄影棚** |

| 禁区 | 原因 |

| ⛔ **不画他的妻子**（叶卡捷琳娜）**不画铁窗、不画 1938 年** | **原版 `purged_kalinin` + `soviet.25` 事件已占了「妻子」这个题**（「加里宁的妻子也有嫌疑」）；且私人悲剧不该上图 |
| ⛔ **不画枪 / 不画刑场 / 不画 1937 年**（全篇） | 与里亚京（`docs/58` §5）· 托姆斯基（`docs/55`）· 施利亚普尼科夫（`docs/61` §5）同一禁区 |
| ⛔ **不画他签名的那些法令**（「三穗法」/ 卡廷的处决令） | ⚠️ **反面的东西** —— 它们在 `docs/62` §2.5 里被明确剔除了，图上也不出现 |
| ⛔ **不画办公室内景** | ⚠️ 与施利亚普尼科夫（`docs/61` §5）同一禁区。**#5 的表决单是「物证特写」，不是内景** |
