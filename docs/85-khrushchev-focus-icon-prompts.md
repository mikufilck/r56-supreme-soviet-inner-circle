## 2. ⭐⭐⭐ 全线母题

> **「纸上的东西，和地上有的东西」**
> —— 六张里每一张都有一张**纸**（课本 / 磅秤后的配额表 / 规划图 / 价格表 / 地图 / 门牌），
> 而每一张纸旁边都有一件**从地上来的东西**（工牌 / 谷子 / 三个村子 / 麦穗 / 一撮土 / 一块牌子的背面）。

⚠️ **这不是「办公室里的一叠纸」**（那是马林科夫 Idx 20 的「卡片与名册」、施利亚普尼科夫 Idx 13 的「制度物证」）。
⭐ **界线一句话**：**马林科夫画的是「卡片本身长什么样」，本线画的是「纸和地面之间那一截」。**

## 4. 色调曲线（整线）

```
1 冷灰（教室）→ 2 冷灰偏暗（秤盘）→ 3 冷灰 + 米白（图纸，线被擦掉）→
4 冷灰 + 麦黄（唯一的彩色，第一次亮）→ 5 冷灰 + 土褐（最暗的一张）→
6 冷灰 + 红漆残屑（收束：几块牌子靠在地上）
```

⚠️ **不要走「越来越亮」的曲线** —— 他这条线的产物**一件件都塌了**（见 `docs/84` 每节点的「代价」列）。
⭐ 唯一的彩色只出现在**第 4 张（麦黄）**，因为那是**他一生唯一一次真的把钱交到了种地的人手上**。
