## 1. 要出的图（共 6 张）

> ✅ **本批的特殊之处 —— 六条文案里四条是「中译本原文」。**
> 中文文库**没有**他的篇目页（`docs/38` §1.4），但**托洛茨基《我的生平》第三十三章
> 〈斯维亚日斯克一月〉整段专讲他** —— 这是本线的主题文献，**重复引是合理的**。
> 另两条出自同代人塞尔日的回忆录（英文，已译）。逐条出处见 `docs/39` §5。

### ⚠️ 整条线的视觉注意事项

1. **母题只有一件事：东边的地。** 本批的关键词是：**河口与桥 / 纵队的行列 / 木屋里的委员会 /
   太平洋岸的界桩 / 沿路铺开的电线 / 雪原上的背影**。
   与已完成批次明确区分开：

   | 批次 | 母题 |
   | --- | --- |
   | 李可夫（`docs/31`） | 工业、机构、供给线 |
   | 季诺维也夫（`docs/34`） | 国际、会场、东方人群 |
   | 加米涅夫（`docs/37`） | 手稿、档案、书与印刷 |
   | **斯米尔诺夫（本批）** | **河、铁轨、雪原、界线** |

2. **六张是一条「一路向东」的位移链，不是一个横排的系列** —— 顺序本身有意义：
   **一座桥（伏尔加） → 一支队伍（乌拉尔） → 一个政权（西伯利亚） → 一条国界（太平洋岸） →
   一张网（全联盟） → 一片雪原（回到起点，但已是结尾）**。
   出图时请**按顺序看一遍**：**视线一路向东推进**，气候一路变冷，天色一路变暗。

3. **E1 是结尾，构图应最饱满**（照布哈林 E1 / 李可夫 E1 / 加米涅夫 E1 的处理）——
   它是全线的最后一个节点，五个前置全完成后才开。

4. 🚩 **画面里不要出现可辨认的文字**（`docs/24` §1）——
   地图、界桩、电报纸带上可以有条纹与色块，但**不要写出可辨认的字母或汉字**。

5. ✅ **本批没有互斥项、没有成对图**（本线是单线）—— 6 张是一体的。

6. ⚠️ **不要画人脸、不要画人物肖像**（本批走苏联国策图标式）——
   第 2、5、6 张需要「人」时，用**行列 / 背影 / 剪影**，不要五官。
