# HOI4 模组开发知识库 — 索引

## 关于可信度（先读这段）

HOI4 **没有官方出版的模组开发手册**。权威来源按可信度排序：

1. **你游戏版本的原版文件**（`steamapps/common/Hearts of Iron IV/`）——唯一 100% 权威，语法最终以它为准。
2. **Paradox 官方 wiki**（`hoi4.paradoxwikis.com`）——Paradox 背书、社区维护，覆盖最全。
3. **官方启动器 / 官方论坛 / 各 DLC 变更日志**。

## 三条最高频踩坑（背下来）

1. **整文件覆盖**：改原版一个文件 = 复制整个文件过来改。目录内不同文件名是合并，同名文件是覆盖。
2. **本地化 BOM**：`.yml` 必须是 UTF-8 **with BOM**，否则中文全部乱码/不加载。
3. **`replace_path` 会清空该目录**：不是"优先使用我的"，而是"原版的全部不加载"。
