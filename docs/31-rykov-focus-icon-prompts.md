## 1. 要出的图（共 5 张）

> ⚠️ **本批的特殊之处 —— 文案不是他本人的话。**
> 李可夫**没有可引用的中文文集**（中文马克思主义文库没有他的页，英文 marxists.org 也没有他的档案）。
> 所以 ①②③⑤ 用的是**列宁 / 托洛茨基**写到他经手的那几个机关时的原话；
> 只有 ④ 连这一档都找不到，退到**后人记述**（**故 ④ 不带引号，一眼看出不是原文**）。
> 详尽来源见 `docs/30` §4。

### ⚠️ 整条线的视觉注意事项

1. **①②③④ 是「行政 / 组织」主题** —— 他这条线的特点不是理论，而是**把东西从无到有建起来**
   （接管工业 → 给红军搞给养 → 把工业与国防接起来 → 扶植一个全新的航空部门）。
   整体气质应当**务实、工业、机构感**，与托洛茨基那批的「军事 / 理论」区分开。
2. **⑤ 是汇合层结局** —— **构图应最饱满**（照布哈林 E1 的处理）。
3. ✅ **本批没有「互斥项」** —— 用**单结局**，所以**不需要**像布哈林 X1 那样刻意做一张「明显更暗 / 更压迫」的图，
   5 张是一体的。

### N1 · 最高国民经济委员会主席

| 项 | 内容 |
| --- | --- |
| **sprite** | `GFX_hof_ic_rykov_supreme_economic_council` |
| **史实** | 1918-04-03 出任最高国民经济委员会主席，整个内战期间在任 |
| **效果** | 工厂产出 **+5%**；民用工厂建造速度 **+10%** |
| **文案（原文节选）** | 「现在最高国民经济委员会担负着一项**困难而又最能收效**的任务。……在剥削者的反抗被彻底粉碎以后，在劳动者学会组织社会主义生产以后，这种原来意义的、狭义的管理机构，旧国家的机构，必定消亡，而**最高国民经济委员会这样的机构必定成长、发展和巩固**，它将担负起**有组织的社会的一切最主要的活动**。」 |
| **出处** | 列宁，1918 年 5 月 26 日《在全俄国民经济委员会第一次代表大会上的讲话》 |
| **意象引导（可选）** | 工厂群 / 高炉与齿轮的庞大组合、委员会式的大厦正面；**不要画人像** |

> 💡 这是全线的**起点**，也是他「从战时混乱里接管工业」的第一次大动作。

### N2 · 劳动国防委员会粮秣特派员

| 项 | 内容 |
| --- | --- |
| **sprite** | `GFX_hof_ic_rykov_food_supply_commissar` |
| **史实** | 1919-07 ~ 1921-08 任劳动国防委员会**红军与红海军给养特派员**（чусоснабарм） |
| **效果** | 陆军组织度 **+5%**；战争支持度 **+5%** |
| **文案（原文节选）** | 「**一个有一定效能的统一供给前线和全军的军需机构逐渐建立起来了。**……同时切不可忘记，我们是在**没有物资储备**的情况下作战的。早在 1919 年，**中央仓库已经告罄**。军衬衣刚刚缝好就送上前线，枪支弹药的情况更糟。图拉的几家兵工厂的产品都是现产现运……」 |
| **出处** | 托洛茨基，《我的生平》第三十六章「专列」 |
| **意象引导（可选）** | 运往前线的列车 / 军需列车与粮袋；**用"供给线"而不是"战场"做主体**（他管的是后方那条线） |

> 💡 关键意象 = 「**没有储备也要供上**」的那种紧绷感，文案里「像一根绷得紧紧的弦」就是这个意思。

### N3 · 劳动与国防委员会副主席

| 项 | 内容 |
| --- | --- |
| **sprite** | `GFX_hof_ic_rykov_labour_defence_council` |
| **史实** | 1921-05-26 就任该委员会副主席（1926-01-19 接任主席，见 E1） |
| **效果** | 工厂产出 **+5%**；**消费品工厂占比 −5%** |
| **文案（原文节选）** | 「国家计划委员会目前的状况根本不可能真正有计划地领导经济工作。……**劳动国防委员会的任务是确定经济政策的基本原则，对经济工作进行全面监督，具体解决其他各级经济组织解决不了的棘手问题。**」 |
| **出处** | 托洛茨基，1921 年 8 月 7 日 |
| **意象引导（可选）** | 一张把工业与国防接起来的会议桌 / 两个机构之间的榫卯与桥梁、案头的文件与地图 |
| **⚠️ 这张可以稍显"重手"** | 它的效果是**压低消费品**换工业 —— 与其说是福利，不如说是**动员**。构图可以比 N1 更紧、更有压迫感 |

> 💡 N3 与 E1 是**同一个机构的两个阶段**（副主席 → 主席），
> **视觉上应当看得出同源**（同一个徽记 / 同一类场景，但 E1 更完整、更宏大），别画成两个不相关的机构。

### N4 · 扶植航空

| 项 | 内容 |
| --- | --- |
| **sprite** | `GFX_hof_ic_rykov_sponsor_aviation` |
| **史实** | 1923 年起任**航空之友协会（ОДВФ，1925 并入 Авиахим）主席**；同年起资助自学成才的飞机设计师雅科夫列夫 |
| **效果** | 科研速度 **+5%**；**雅克夫列夫设计局 MIO 规模 +2** |
| **文案** | ⚠️ **本条不是原文节选**（唯一一条）：<br>「雅科夫列夫最初的一批飞机，家族名就叫 **АИР** —— 以阿列克谢·伊万诺维奇·李可夫命名。第一架飞机取名「А. И. 李可夫」，是为了感谢这位自学成才的设计师从 1923 年刚入航空业起，就持续得到航空之友协会（ОДВФ）及其后继者阿维阿希姆的支持；而自 ОДВФ 1923 年成立起，这一组织的主席就是李可夫本人。航空之友协会当年就发展到二百万人，**АИР 这个名字一直用到 1937 年的 АИР-18**。」 |
| **出处** | 俄文维基百科「阿列克谢·伊万诺维奇·李可夫」条「纪念」节 +「Осоавиахим」条 |
| **意象引导（可选）** | 早期双翼 / 单翼飞机 + 机翼上的字样（**注意：画面里不要出现可辨认的文字**，见 §1 硬性要求）；也可以用「飞机 + 人群认购/募捐」的群众性运动感 |

> 🚩 **命令 AIP 系列飞机以他命名**是本条最有辨识度的事实。
> 但**画里不能出现字母** —— 若想表达「以他命名」这层意思，请用**象征**（如机身上的绶带、留白的铭牌位）而不是写字。
>
> 💡 这一条和游戏里的**雅克夫列夫设计局**（军事工业组织）挂钩 —— 它是**全新的部门**，
> 所以构图可以比其余四条**更"新"、更明亮、更有未来感**，这是全线的收束前奏。
