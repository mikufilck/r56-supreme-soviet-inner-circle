## §1 规定是什么

**避重的范围 = 能同席的人。**

- 做某人（记为 X）的个人线之前，跑 `build/gen-hof-ic-s3.ps1` 读 **§0b 席位互斥展开**
- **只需避「排掉名单之外」的人**
- 与 X 在**排掉名单里**的人 —— 两人**永远不可能同席** → **题材重叠不会撞车** → **不必避**

⚠️ **注意「营 × 营」有规则的组合才是互斥**；**同营之间大多没有规则**：

| 组合 | 有规则吗 |
| --- | --- |
| `left` × `right`（R2 理论完全对立） | ✅ 有（24 对） |
| `workers` × `left`（R1 工会大辩论） | ✅ 有（6 对） |
| `regime` × `left` / `right` / `united` / `workers` | ✅ 有（39 对） |
| **`neutral` × 任何营** | ⛔ **无**（中立营的语义 = 不因**理论**与任何营互斥） |
| **`left` × `united`** · **`right` × `right`** · **`regime` × `regime`** · **`left` × `left`** … | ⛔ **无** |
| R1 单独项（历史交恶 / 血债） | ✅ 有（5 对，跨营照常生效） |

## §4 结论：**有没有「确实有必要写作多线」的？**

### ⛔ **答案：没有。**

**三条理由：**

1. **解禁出来的全是【1 个节点】，不是【1 条支线】。**
   放宽规定解禁的是「原来以为撞车的某一件具体的事」，最多给现有单线**补 1 个节点**。
   而「多线」需要的是**第二条轴**。

2. **它们全都在现有主干的同一根轴上。**
   按 `docs/23` **判据 B**（轴能不能从根推出来）与 **判据 C**（产物能不能抬到国家制度层）——
   普列奥布拉任斯基的「左派共产主义者」、托姆斯基的「工会大辩论」都是**主干内部的事**，
   把它们拆成第二条支线会**违反判据 B**（换个人来也成立 → 不是「轴」，是「事件」）。

3. **单线是【用户口径】，不是「被避重逼出来的」。**
   本项目**连续 9 轮**都取 **单线 5 节点 + 1 单结局**，且用户**多次主动砍支线**：
   - 加米涅夫：**13 块 → 5 块**（`docs/35`，「BC 支线也砍了」）
   - 施利亚普尼科夫：**删 A2**（`docs/60`，第四版）
   - 索柯里尼柯夫 / 里亚京：**删节点**
   → **单线是设计口径，不是避重的副产品。**

## §5 其他 19 人为什么没有第二条线（用户追问）

> 用户问：「**也就是其他人确实不像是托洛茨基或者布哈林那样在多个方面有贡献对吧，没得做第二条线？**」

### ⚠️ **基本对，但有一处必须更正 —— 原因不只是「贡献面窄」**

**先看事实**：22 人里做成多线的只有 **3 人** ——
**托洛茨基（17 块）· 季诺维也夫（11 块 / 3 支线 / 2 互斥结局）· 布哈林（9 块 / 3 级官衔链）**；
**其余 19 人全部是单线**（4–6 块 + 1 单结局）。**这一点你说得对。**

**但**「贡献面窄」只能解释其中一部分。复核时发现 **7 个人的「面」其实并不窄** ——
他们是**别的原因**才停在单线：

### 📌 所以真正把 19 人压成单线的是**三个原因**，不是「没贡献」

1. **判据 B（支线必须从「根 / 主干」推出来）** —— 🚩 **这一条有两次真实代价**：
   **加米涅夫（13→5 块）** 与 **施利亚普尼科夫（两版全废）**。他们的第二、第三个面**有史实**，
   但**不是从主干推出来的，是拼上去的** → 这就是「没得做」的**准确含义**：
   **不是没材料，是材料长不到那根轴上。**
2. **招牌被占（第二面 = 别人的第一面）** —— 拉狄克 / 图哈切夫斯基 / 彼得·斯米尔诺夫 / 伏罗希洛夫。
   ⭐ 这四人现在的主干，**全是「退回一步」之后才找到的**（`docs/35` §5.1 的运用，已用到第 8 次）。
3. **单线是你的口径** —— 剩下的人（李可夫 / 斯米尔诺夫 / 谢列布里亚科夫 / 斯米尔加 / 托姆斯基 /
   加里宁 / 李维诺夫 / 索柯里尼柯夫 / 马林科夫 / 赫鲁晓夫）**本来就没有值得单列的第二根轴**，
   而且你**多次主动砍支线**（加米涅夫 13→5 · 施利亚普尼科夫删 A2 · 索柯里尼柯夫 / 里亚京删节点）。

### ⭐ 那 3 个人为什么能多线？—— 他们有一个共同点

**托洛茨基 / 季诺维也夫 / 布哈林 的贡献，跨越了【互不相干】的领域，而且每个领域都有他们自己的著作。**

- 托洛茨基：军事 · 经济 · 共产国际 · 文学批评 · 党内民主 —— **著作量 22 人里最多**
- 季诺维也夫：「向外（共产国际）」与「向内（党内）」是**两根真正独立、且别人没占的轴** ——
  他有**完整中文文集（26 + 3 份一手件）**→ **11 条文案全是本人原话**
- 布哈林：理论 · 经济 · 共产国际 · 反右 —— **3 级官衔链 + 9 块**

📌 **结论一句话**：**「多线」要的不是「贡献多」，是「有第二根轴，且那根轴上的文案拿得出来」。**
**其余 19 人里，有 7 人是被「招牌被占」或「判据 B」挡住的，不是没贡献。**
