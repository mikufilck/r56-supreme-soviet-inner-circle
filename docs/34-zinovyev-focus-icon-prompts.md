## 1. 要出的图（共 11 张）

> ✅ **本批的特殊之处 —— 文案全是他本人的原话。**
> 季诺维也夫**有完整的中文文集**（中文马克思主义文库有他的专页，本轮抓了 **26 + 3 份**一手件）。
> 所以 **11 条全部是原文节选**，**没有一条退到「他人记述」**（这点比李可夫那批好）。
> ⚠️ **唯一需要说明的**是 **A2**：21 条件的**原文报告**（1920-07-29）中文文库没有，
> 引的是他 **1921-11 回顾时**提到「著名的二十一条」的那一句。详尽来源见 `docs/33` §4。

### ⚠️ 整条线的视觉注意事项

1. **全线的母题是「共产国际」（第三国际）** —— 不是苏俄国内。
   这批图标里应当反复出现**国际性 / 跨国的符号**（多国旗帜、地图、代表大会会场、
   各民族人群），与托洛茨基那批的「军事 / 内战」、李可夫那批的「工业 / 机构」**明确区分开**。
2. **三条支线的气质各有侧重**（便于出图方分组把握）：
   - **A 支线（缔造 + 立规矩）→ 庄严、组织、纪律感** —— 会场、纲领、印章、架构图
   - **C 支线（世界革命的期限与道路）→ 辽阔、地理、朝东的视线** —— 地图、东方人群、路线
   - **D 支线（党与工会）→ 内部、基层、人群** —— 党的组织、工会会众
3. **两个结局（E1 / E2）是「同一个国际的两种形态」，要能一眼看出是一对** ——
   同一母题、同一构图骨架，**只有色调与密度不同**：
   - **E1 铁板一块的国际 = 秩序 / 收紧 / 冷硬**（想想「纪律」）
   - **E2 群众的国际 = 敞开 / 涌动 / 暖**（想想「人流」）
   > 照布哈林那两个互斥结局的处理（`docs/27`）：**刻意做出可见差异**，让玩家一眼知道是两条不同的路。
4. 🚩 **画面里不要出现可辨认的文字**（`docs/24` §1）—— 横幅、旗帜上可以有条纹图案，
   但**不要写得出字的字母或汉字**。
