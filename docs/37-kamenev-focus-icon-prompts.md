## 1. 要出的图（共 5 张）

> ✅ **本批的特殊之处 —— 5 条文案全部是一手件。**
> 加米涅夫**有中文专页**（19 条）+ **英文 6 篇**（中文库没有）。本轮全部抓下，落盘 `tmp/kamenev/txt/`。
> ⚠️ **其中三张（A1 / A4 / E1）引的是他同一篇长文** —— 《伊里奇的文学遗产与列宁全集》
> （英文，载《共产国际》第 1 期）。这是本条线的**主题文献**，重复引是合理的。
> 逐条出处见 `docs/36` §5。

### ⚠️ 整条线的视觉注意事项

1. **母题只有一件事：纸。** 本批的关键词是：**手稿 / 词典 / 并排的文件 / 档案墙 / 印刷机**。
   与已完成的三批明确区分开：
   | 批次 | 母题 |
   | --- | --- |
   | 李可夫（`docs/31`） | 工业、机构、供给线 |
   | 季诺维也夫（`docs/34`） | 国际、会场、东方人群 |
   | **加米涅夫（本批）** | **手稿、档案、书与印刷** |
2. **五张是一条昇华链，不是一个横排的系列** —— 它们的顺序本身有意义：
   **手稿 → 体系 → 论战 → 档案馆 → 巨著**。出图时请**按顺序看一遍**：
   后一张应当比前一张更“厚”、更“完整”、更“重”。
3. **E1 是结尾，构图应最饱满**（照布哈林 E1 / 李可夫 E1 的处理）——
   它是全线的最后一个节点，四个前置全完成后才开。
4. 🚩 **画面里不要出现可辨认的文字**（`docs/24` §1）——
   稿纸、书脊、档案标签上可以有条纹与色块，但**不要写出可辨认的字母或汉字**。
5. ✅ **本批没有互斥项、没有成对图**（互斥项与 B/C 支线已砍）——
   5 张是一体的，**不需要**像布哈林 X1 / 季诺维也夫 E1·E2 那样刻意做差异。
