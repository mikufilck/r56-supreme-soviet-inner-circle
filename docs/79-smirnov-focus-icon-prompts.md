## 2. 全线视觉母题：**「一间机关里的物证」**

⭐⭐ 本线讲的不是「海军造了什么」，而是「**管海军的那个机关是怎么长出来的**」——
所以六张图的母题是**制度的物证**，一级比一级正式：

**一块门牌 → 一张海图 → 一架水上飞机 → 一份报纸 → 一张长桌 → 一枚盖章的决议**

⭐⭐⭐ **一句话**：**这一条线里【一条船都没有** —— 因为他在造的不是船，是**管船的那个机关**。
（这正是与原版海军线 `SOV_expand_the_red_fleet` / `SOV_an_oceangoing_navy` / `SOV_pc_of_the_ussr_navy` 等的**画面界线**：
原版画舰队与船坞，本线**只画纸、牌子、桌子、章**。）

## 3. 🚩🚩 色调纪律（`docs/23` **判据 G**）

> **判据 G：色调只能来自「画面里那个东西本身的颜色」。** 自检 —— 把画面里的物体逐个念一遍：
> **如果那个色不属于其中任何一个物体，它就超标了。**

| # | 允许的色 | 来源（画面里的什么东西） |
| --- | --- | --- |
| 1 | 搪瓷白 / 素墙灰 / 门洞黑 | **那块牌子 / 墙 / 门洞** |
| 2 | 纸黄 / 钢青灰 | **海图纸 / 分规** |
| 3 | 机身灰白 / 浮筒深灰 / 水面青灰 | **水上飞机 / 水面** |
| 4 | 报纸灰 / 纸白 | **报纸 / 纸边** |
| 5 | 呢面暗绿 / 木色 / 水杯透明 | **长桌 / 椅子** |
| 6 | 🚩 **唯一的红**：印泥红（偏暗、边缘晕开） | **那枚圆章的印泥** |

⛔ **不许**：整幅上冷蓝夜景、整幅青绿、赛博霓虹、大面积饱和红。
⭐ **本线的「红」只出现在第 6 张的那枚章上**，而且它是**印泥**的红 —— 不是血腥，不是旗帜。
