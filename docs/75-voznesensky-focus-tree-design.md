## 1. 主干与推导

### 1.1 根 → 主干（详见 `docs/74` §2）

⭐⭐⭐⭐⭐ **根 =「计划是同自发势力作斗争，不是同它结合」**
> 出自 **1931-10-08《为实现当前阶段的计划而斗争》**（**他自己写的，中文原文**）：
> 「社会主义计划是**在斗争中**而不是在同小资产阶级自发势力和由它产生的资本主义因素的**结合中**发挥作用的。」
> ⭐ 同篇还有一句把「迁就现实」和「凭空乱写」**一起封掉**：
> 「**同轻率地作空头『计划』的癖好和过火行为作斗争也是必要的。**」

⭐⭐⭐⭐⭐ **主干 =「把『拿得出多少』变成一切决定的依据」**
> ⭐ **一句话记法**：**别人在争「要多少」，他只回答「有多少」。**

**推导链**（每一环都有史实或原文，详见 `docs/74` §2.2）：
**1931 写下立场 → 1935 做一张市的表 → 1938 表变成全国的 → 1941-08 表在战争里被重排 → 1941-42 表开始决定战役 → 1947 给那个时代的经济命名**

> ⭐⭐ **首尾同轴**：
> **根 = 一个 27 岁教员在《真理报》上写下的立场；E1 = 一个国家在只剩一半工业区时，按「有多少」把战争打完。**
> **同一条「不迁就、不空写」的规则，从纸上走到了国防委员会的桌上。**

### 1.2 ⚠️ 为什么主干**不是**「他把工业搬到了乌拉尔」

🔴🔴 **原版有 `SOV_move_industry_to_the_urals`「向乌拉尔转移工业」**，描述就是「必须将其**疏散**到安全地带」。
→ ⛔ **「搬工厂」这个题被原版占了**。
→ ✅ **本线做的是【搬到哪去、以及在那里【再建一份】】** ——
**1941-08-07 国防委员会第 421 号决议《关于安置被疏散企业的程序》把这件事交给了国家计委**：
各人民委员部**必须与国家计委协商**确定工厂的**最终落脚点**，并组织**重复生产**（`дублирующие производства`）。
📌 **原版做的是「搬」；本线做的是「决定往哪搬，以及为什么在那里再造一个」。**

### 1.3 ⚠️ 为什么主干**不是**「战时经济」（**名字撞车**）

🔴🔴🔴 **原版有 `SOV_war_economy`，中文名就叫「战时经济」**（「我们必须将我们的经济转入战时状态」）。
→ ⛔ **E1 不能叫「战时经济」**。
→ ✅ 本线 E1 = **「卫国战争的政治经济学」** —— 取自**同一本书的引言第一段**（`Военная экономика СССР в период Отечественной войны`，1947：「社会主义政治经济学中一个专门篇章」）
→ ⛔ **也不用「苏联战时经济」**（= 书名的简称，与原版 `SOV_war_economy` 的中文名**只差两个字**）
→ ⭐⭐ **首尾呼应**：与「根」A1《论政治经济学的对象问题》（1931）是**同一门学问** —— 根是一篇论文的题目，E1 是这门学问里以他这件事命名的一个篇章
→ 📌 **2026-09-20 用户口径「有更好的可以采用更好的」**（`docs/23` 判据 J）→ 由「苏联战时经济」改取本条；**focus id 保留 `_the_war_economy`**（改 id 会连带 sprite 名与美术文件名，代价大于收益）
—— **史实专名**（判据 F 过）+ **与原版国策【不同名】**。
