## 2. 第 1 步 · 史实结构化（**不是分类，是建模**）

### 2.1 ⚠️ 先改问法：他不是理论家，SOP 的「根→主干→推论」要换一种问法

`docs/23` 第 1 步那套（「根理论 → 主干理论 → 推论」）是**为托洛茨基这种理论家设计的**。
李可夫是 **政府首脑型行政者**（`docs/10` L239 就这么归类），
**他没有成体系的理论著作**（§0 已证：中文文库 0 篇目）。

→ 所以问「他的根是什么」时，答案不是一条**理论**，而是一条**立场/方法**。

## 8. 核实结果（2026-09-16 已查）

> 来源：`tmp/rykov/verify/`（`en_prohibition` · `en_vodka` · `ru_rykov` · `ru_monopoly`）
> 抓取工具 `build/verify-rykov*.ps1`。

### 8.1 ✅ #1 酒类专卖（Rykovka）—— 查到了，但**归属需要修正**

| 问题 | 结果 | 来源 |
| --- | --- | --- |
| 专卖什么时候恢复的？ | **1924 年 1 月**：`Пятая монополия на алкоголь была введена в январе 1924 года` | `ru_monopoly` |
| 那是他的功劳吗？ | ⚠️ **不是**。他 **1924-02-02** 才就任人民委员会主席，专卖恢复**早他一个月**（当时他是副主席） | `ru_monopoly` + `[W]` |
| 另有说法？ | 英文条目把 1925-10-04 允许 40% 谷物酒精销售算在**斯大林**头上 | `en_prohibition` |
| 「Rykovka」到底是什么？ | **30 度伏特加**：`Тридцатиградусную водку в народе называли «рыковкой»` | `ru_rykov` |

> ⚠️ **修正**：不能写成「李可夫建立了酒类专卖」—— 那是**史实错误**。
> 正确表述是「**他主政时期（1924–30）的酒类专卖，民间把便宜的 30 度伏特加叫「李可夫卡」**」。
> **他是这套制度的主持者，不是倡议者** —— 这比「缔造红军」那种「从无到有」弱一档。

### 8.2 ✅ #2 1924–30 的具体政策 —— 查到一条硬的（**财政**）

> `[W]`/`ru_rykov`：1920 年代末讨论联盟预算时，**他反对其它加盟共和国预算增长快于俄联邦**，
> 并称「让所有其它民族『靠俄国庄稼汉过活』是不可容许的」。原话：
>
> **「英国的殖民政策，是宗主国靠殖民地发展；而我们是殖民地靠宗主国发展。」**
>
> （`Колониальная политика, например, Великобритании, заключается в развитии метрополии за счёт колоний,
> а у нас — колоний за счёт метрополии.`）
>
> ⚠️ 这次发言被定性为「**大国沙文主义**」。**属于「反对型」主张**，
> 用不用、怎么用，要按 `docs/23` §2.5 的「三问」判。

### 8.3 🎁 意外收获：**АИР 飞机 / 航空之友协会**（比酒类专卖强得多的「做成了的事」）

> `ru_rykov`：他自 **1923 年 ОДВФ（Общество друзей воздушного флота，航空之友协会）成立起任主席**
> （后继机构 Авиахим 亦然）。雅科夫列夫早期设计的飞机**全系列以他命名**：
> 第一批叫 **АИР** = **А**лексей **И**ванович **Р**ыков，第一架甚至直接叫「А. И. Рыков」，
> 后续型号一路排到 **АИР-18**（1937 年他被清洗为止）。
>
> | 四要素 | |
> | --- | --- |
> | 主体 | ✅ 他（ОДВФ/Авиахим 主席） |
> | 动作 | ✅ 支持并资助一个**业余航空设计者** |
> | 从无到有的产物 | ✅ **АИР 系列飞机**（后来长成雅科夫列夫设计局） |
> | 可考年份 | ✅ 1923 年起 |

> 💡 **这条比酒类专卖强得多**，因为它有**「从无到有的产物」**——
> 与「缔造红军」同型（`docs/23` 第 1b 步的四要素）。
> 而且它天然是**奠基性节点**（`docs/23` 第 3 步：奠基性最强的放支线末端）：
> 他扶植的那个业余设计者，后来成了苏联航空的支柱。
>
> 📌 **建议**：作为**单线的第 4 个节点（末端，奠基性）**—— 写法见 **§9**。
> 但 `[待]` **ОДВФ 主席这一职务需再核一次**（俄文条目把 1923 与「苏联人民委员会主席」写在一句里，

### 9.1 德国蓝本：`GER_autonomous_organization_todt`「托特组织自治」

出处：`common/national_focus/germany.txt` L18509。

| 项 | 值 |
| --- | --- |

| 前置 | `prerequisite = { focus = GER_form_organization_todt }` |
| 互斥 | `mutually_exclusive = { focus = GER_plenipotentiary_of_armaments focus = GER_plenipotentiary_of_the_four_year_plan }` |
| 定位 | `x = 0` `y = 1` `relative_position_id = GER_form_organization_todt`；`cost = @inner_circle_time_tier_2`；`text_icon = GER_inner_circle_focus_style` |

**`completion_reward` 分三段**：

```text
① custom_effect_tooltip = { localization_key = GER_ascended_character_trait_swap_tt  CHARACTER = GER_fritz_todt }
② swap_ideas = { remove_idea = GER_todt_reich_engineer  add_idea = GER_todt_reich_minister_of_armaments }   # 升官衔
③ if   = { limit = { has_idea = GER_organization_todt }
           swap_ideas = { remove_idea = GER_organization_todt  add_idea = GER_organization_todt_improved } }  # 升组织
   else = { effect_tooltip = { swap_ideas = { ... } } }   # 没有该 idea 时只显示提示，不报错
```

> 💡 **德国那套的关键**：托特组织是一个 **idea（民族精神）**，**不是 MIO** ——
> 定义在 `common/ideas/GER.txt` L5846（`GER_organization_todt`）/ L5872（`..._improved`），
> 各带 `traits = { ..._trait }`。**升级 = `swap_ideas` 一对一换**，
> 与我们既有的官衔链（`docs/26` §7.4）是同一手法。
