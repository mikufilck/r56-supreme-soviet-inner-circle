## 9. 第 4 步 · 聚类 → 支线；第 5 步 · 跨簇钩子

### 9.1 簇数 = **1** → 支线数 = **1** → **单线**

五件事是**同一条过程的先后环节**，不是并列的分类清单：

**守住桥头堡（①） → 打赢并结成队伍（②） → 把它建成政权（③） → 再往东一步、用缓冲国挡住日本（④） → 用邮电网把全国连起来（⑤）**

`docs/23` §2 的原则是「**3 簇 → 3 条支线，不要硬凑到 5**」；**只剩一簇时就是一条线**。

### 9.2 跨簇钩子：⛔ **无**

只剩一个簇，自然没有「簇与簇之间」需要 `prerequisite` AND 连接的地方（与加米涅夫砍枝后的结论一致，见 `docs/36` §6）。

### 9.3 🚩 **我主动检查过「有没有第二个簇」—— 没有**

按用户 2026-09-17 对加米涅夫的教训（「**一条支线能不能立住，看的不是『有没有史实』，
而是『能不能从根 / 主干推出来』**」）：

> 他 1923 之后的**反对派生涯**（四十六人声明 / 八十三人声明 / 投降派组织）确实有史实、
> 有大量一手件 —— 它**看起来像是天然的第二条支线**。但它是**从另一个人的主干推出来的**
> （托洛茨基、季诺维也夫的主干），**不是从他的主干推出来的**。
> → **不拆支线**。这正是加米涅夫 B / C 支线被砍的同一个错误，**这次不重犯**。
