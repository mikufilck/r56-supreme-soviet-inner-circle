## 1. 主干与推导

### 1.1 根 → 主干

```text
        根：一个由别人出钱、用工厂的车间送出来的农家孩子
        （12 俄里外那所小学是几个村子唯一能读书的地方；
          18 岁进兵工厂，1896 进普梯洛夫，「在工厂里第一次认识了马克思主义」）
                          │
                          │  ⭐ 他比谁都清楚：一个村里的人要走到「上面」有多难
                          ▼
        主干：一个能被普通人找到的国家
        （一句话记法：别人都在做「国家做什么」，他做的是「国家找不找得到」）
                          │
      ┌────────┬──────────┼──────────┬──────────┐
      ▼        ▼          ▼          ▼          ▼
   农民出身的元首  扫除文盲   全民国家    接待室      没有根据的行动
   A1 1919-03      A2 1923    A3 1926     A4 1920s-40s A5 1932-05
```

⭐ **一句话记法**：**别人都在做「国家做什么」，他做的是「国家找不找得到」。**
📌 这句同时是**与三处「机关线」的分水岭**（§8.1 第 1 条）。

### 1.2 五步的推导（**每一级都必须由上一级推出来**）

| # | 上一级推出什么 | 本节点回答的问题 | 产物（**国家级**） |

| **A2** | 坐在上面了，来的人得说得上话 | **怎么让人说得上话？** | ⭐⭐⭐ **扫除文盲** —— 协会名下 **1.1 万个点**，1930 年代末识字率逼近 90% |
| **A3** | 人会读会写了，读到的这个地方是谁的？ | **这个国家是谁的？** | ⭐⭐⭐ **苏联政治话语里第一次提出「全民国家」** |

| 判据（`docs/23`） | 结论 |
