## 四、汇总与排期参考

| 模块 | 国策数 |
| --- | --- |
| A 核心圈（入口 + 专属，18 角色） | **80 ~ 90** |

**排期含义**（按每批次 5~10 个国策 + 一次 `error.log` 验证计）：

- 核心圈：约 **10~12 个批次**
- 中苏联合：**1~2 个批次**
- 互助会通用线：**3 个批次**
- 互助会国别分支：**7~10 个批次**（每国 1 个批次）
- **总计约 22~27 个批次**
