## §1 定性：「专用线」= 什么

| 项 | 定案 |
| --- | --- |
| **是什么** | **需求 C 的 S6「国别专属分支」** —— 与 S5 那三条【通用线】（经互会 / 情报局 / 华约，**大家都一样**）相对：**一国一条、只有该国看得见的那条线** |
| **写法** | ⭐⭐ **完全照 R56 阿富汗**萨达巴德条约 **那一棵**（`docs/un-focus/04` 逐块解剖）—— 一个文件、**块全部是 `joint_focus`**（连头也是）、**头是唯一带 `offset` 的块**、**子节点零 `offset` 纯 `relative_position_id` 小增量串链** |
| **门控** | ⭐ **萨达巴德的原写法 = `available = { tag = <国> }`**（实测 9 处：`SSB_baghlan_sugar_factory_branches` 等）—— 一国专属的节点就是靠这个只给该国看 |
| **不做什么** | ⛔ 不做「苏共中央国际部 / 第一书记会议」那类**全局机制**（已在 S5 政治线里）· ⛔ 不做各国自己的内政（那是各国原版树的事） |

> 📌 **与 S5 的分工一句话**：
> **S5 = 「这个阵营共同做了什么」**（三条通用线，人人可点）；
> **S6 = 「苏联和这一国之间发生了什么」**（一国一条，只有那一国可点）。

## §4 骨架（照萨达巴德，逐条可抄）

```
common/national_focus/hof_s6_country_branches.txt      ← 新建，UTF-8 无 BOM + CRLF
  头（joint_focus，唯一带 offset 的块）       id = hof_s6_<主题>
   ├─ 该国专属支线（available = { tag = X }）   × 19
   └─ （可选）跨国的末尾节点
```

| # | 规则 | 依据 |
| :-: | --- | --- |
| 1 | **文件根级定义**，⛔ 不写 `focus_tree = { }` | 萨达巴德 18 块全是根级 |
| 2 | **块全部用 `joint_focus`**（连头也是） | 萨达巴德 18/18；⭐ `shared_focus` **不支持** `completion_reward_joint_originator` / `_member`（本项目 S5 实测被抓过，`docs/99` §47.13） |
| 3 | **头 = 唯一带 `offset` 的块**；子节点 **0 条 offset** | 萨达巴德实测（10 : 0） |
| 4 | **子节点 `relative_position_id = 上链父节点`，小增量** | 萨达巴德 17 处，x ∈ [−3,+4] · y ∈ [1,7] |
| 5 | **一国专属的节点写 `available = { tag = <国> }`** | 萨达巴德 9 处原写法 |
| 6 | **宿主树里各写一行 `shared_focus = <头 id>`** | 由 `sync-from-r56.ps1` 读 `build/inject-*.txt` 自动并入（**不要手抄名单**） |
| 7 | **偏移判据 = `has_focus_tree` ＋ 必要时叠 `tag`** | 萨达巴德：`tag` 管哪个国家、`has_focus_tree` 管这个国家当前用哪棵树，**两者都要写全** |

### §4.1 ⬜ 摆位：三案待裁（判据 J）

| 案 | 做法 | 代价 / 风险 |
| --- | --- | --- |
| **甲 · 萨达巴德式** | 头上写 **19 条 `offset`**（判据 `has_focus_tree`，同一国多树时再叠 `tag`），把整条带子分别卡进每棵宿主树的**空位** | ⚠️ **要逐棵知道空位在哪**；S5 那次就是因为「MaxX 表测错」被 offset 送进树身里（`docs/99` §47.14）→ 不可靠 |
| **乙 · S5 式（推荐）** | **0 条 offset**，整条带子固定在**所有树的下方**：头 `(0, 31)`，子节点 `y = 31 + row` | ✅ **不用量任何一棵树**、结构上必然为空（现场实测最深 23）· ⚠️ 要往下滚（与 S5 同样的问题，用户此前已接受） |
| **丙 · 混合** | 头 `(0, 31)` 不用 offset，但**每国的支线各给一个 `x` 列位**，让 19 条支线横向铺开 | ✅ 视觉上「一国一列」很整齐；⚠️ 仍要往下滚 |

> 📌 **推荐【乙】**：S5（59 块）占 `y ∈ [24, 30]`，S6 从 **31** 起接着往下排，两棵树的带子**首尾相接不打架**；
> 宽度上 19 条支线各占一列的话，`x ∈ [−27, +27]`（列间隔 3 格）—— 横向更宽也不影响（y 已在所有树下方）。
> ⚠️ **若走甲**：必须【逐棵实测空位】，且**不许**再用任何写死的坐标表。
