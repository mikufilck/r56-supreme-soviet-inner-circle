## §1 机制（官方 wiki + 原版实测）

依据：`docs/reference/wiki/National_focus_modding.txt` **§Shared focuses / §Joint focuses**（L2167–2283）+ 原版实测。

| 项 | 结论 |
| --- | --- |
| 写在哪 | `shared_focus = { }` 与 `joint_focus = { }` 都写在**文件根级**，与 `focus_tree = { }` 平级；**没有** `common/joint_focuses/` 这个目录 |
| 怎么挂进树 | 树内写 **`shared_focus = <头 id>`** → ⭐ wiki 原文：「This will add the specified shared focus **and every shared focus that's connected to it via prerequisites**」⇒ **头 + 一串 `prerequisite` 把整条带子带出来** |
| `shared_focus` vs `joint_focus` | **两个层次**（不是同义词）：`shared_focus` = 出现在多棵树里、**各国各自完成**；`joint_focus` = shared 的**子集**，**完成度在参与国之间共享**，由 `joint_trigger` 决定「谁是 joint」 |
| 奖励三档 | `completion_reward` = **每个 joint 国** · `completion_reward_joint_originator` = **只有直接完成的那一国** · `completion_reward_joint_member` = **其余 joint 国** |
| `offset` | **通用属性**（不是 shared 专属）—— `{ x y trigger }`，x / y **加到**该 focus 的位置上，**在国策树加载时判定**；事后可用 `mark_focus_tree_layout_dirty` 刷新 |
| 子节点跟不跟着走 | ⭐⭐ **跟**。wiki 原文：「only use the later `offset = { ... }` **only in the top focus of each branch** that requires to be moved, **due to updates to the children focuses' positioning**」⇒ **offset 只挂在头节点上** |
| 坐标单位 | **x = 96 px/格 · y = 130 px/格** |
| ⚠️ 崩溃条件（wiki 明列） | ① `shared_focus` **指向不存在的 id** → 进主菜单时崩溃 ② **树里没有非共享国策**时挂共享国策 → 崩溃（我们的树都是完整树，安全） |

## §2 摆位：**树的最右边** + **保险基准**

### §2.1 最终写法（三条口径合起来）

```
shared_focus = {
    id = hof_ma_<头>

    x = 0        # ← 保险基准的 x
    y = 24       # ← 保险基准的 y：所有树的 Y 最大只有 22 ⇒ 落在这里【压不到任何一棵树】

    offset = { x = <该树 X 最大 + 24>  y = -24  trigger = { has_focus_tree = <树 id> } }   # × 21 条
    ...
}

# 子节点（59 个 joint_focus）：x ∈ [−21, +21] · y ∈ [1, 6]（15 条支线各占一列，列间隔 3 格），
#   ⭐ relative_position_id 【一律 = 头节点】（单一锚点，永不累加），
#   x / y 直接写【相对头节点的绝对格位】；prerequisite 仍按上链父节点写（支线内成链）；
#   【一个 offset 都不写】
```

| 口径 | 怎么落 |
| --- | --- |
| **② 要保险基准** | 基准取 **(x = 0, y = 24)** —— ⭐ **这是一个【本来就安全】的位置**：y = 24 比 20 棵树里最高的 SWE（Y 最大 22）**还低 2 格**，所以万一某个国家没有 offset 命中，带子落在 (0, 24) 也**不会压到任何一棵树的国策**（北欧的保险基准是 `x = 40 y = 15`，同一个思路） |
| **③ y 按甲** | **20 条 offset 的 y 一律 = −24**（把带子从 y = 24 拉回 **y = 0**），不做逐国 y 微调 |
| **头部落点** | `x = 该树 X 最大 + 24`、`y = 0`。⭐ **为什么要 +24 而不是 +4**：支线带子从**头节点往左还要伸 21 格**（见 §3.1），头部落点必须让**带子的最左边**也落在树的右侧（maxX + 3 > maxX） |
| **摆位单位** | ⭐⭐ **`x` / `y` 是【相对 `relative_position_id` 那一格】的增量**，**不是绝对坐标**。这是本项目踩过【三次】的坑，见 v4 → v6 那三张表 |
| **锚点纪律** | ⭐⭐⭐ **58 个子节点的 `relative_position_id` 一律 = 头节点**，`x` / `y` 直接写「相对头节点的绝对格位」 —— 这样**无论引擎解不解析相对关系，落点都不重叠**（解析：头 + 格位；不解析：格位本身） |

⭐⭐⭐ **v4 的原因（当时的推断 —— ⛔ 已被 §2.5 证伪）**

官方 wiki（`docs/reference/wiki/National_focus_modding.txt` L466–484）原文两点：

1. 「`relative_position_id = TAG_other_focus` … adding the **x** and **y** values to the other focus' position」
   —— 它是**加法**，`x` / `y` 是**增量**，不是绝对坐标。
2. ⚠️⚠️ 「**and the focus must also be located in the same focus tree for the argument to work properly**」

⇒ `shared_focus` / `joint_focus` 声明在**文件根级**（不在任何 `focus_tree` 里），
**只要这个相对解析有一处没落地，小增量就会被当成【绝对坐标】**：
15 条支线的第一个节点会全部落在那几个**相同**的增量值上 ⇒ **叠成一坨**。

**实测证据（用原版北欧做的对照）**：把 `nordic_shared.txt` 那 51 个增量当绝对坐标读，
会撞上瑞典树自己的 **129 个国策**（169 个里）—— 原版不可能发这种东西，
所以北欧那条路是通的；但**本线没必要赌这个**。

✅ **v4 的写法（对两种解释都安全）**：

| 解释 | 落点 | 结果 |
| --- | --- | --- |
| 相对解析**生效** | 头 + 格位 | ✓ 就是设计的位置 |
| 相对解析**不生效** | 格位本身 | ✓ 仍然**互不重叠**（格位本身是唯一的） |

⇒ **`build/gen-hof-ma-common-lines.ps1` 里加了两条断言把这件事钉死**：
`58 个子节点占 58 个互不相同的格位（无叠格）` · `所有子节点 relative_position_id 一律 = 头节点`；
`build/verify-s2.ps1` §13h 也在**读回生成文件**后重新验一遍。

📌 **纪律（写进记忆）**：**在根级 `joint_focus` / `shared_focus` 里，不要用「锚上一个节点 + 小增量」的写法** ——
一律**锚同一个节点（头）**，`x` / `y` 写「相对那个锚点的绝对格位」。

## H. 成员资格与后来加入者（2026-09-27）

通用线的资格是共产主义政体，并且为苏联本身、苏联附庸或苏联同阵营国家。入口 `available`、联合国策 `joint_trigger` 与持续数值／机构奖励共用判据 `hof_ma_eligible`。2026-09-29 用户追加例外：国际经济合作银行、Intermetall、友谊输油管道、联合电网四个节点完成时，对**所有挂载经互会通用线的国家**发放一次对应的首都资源，不论其是否符合成员资格或参加共同完成。国家旗标按节点去重。其他数值、机构 idea、工厂等效果仍按资格判断；国策解锁及共同完成的参与资格也未改变。

苏联用 `hof_ma_done_<国策 id>` 旗标保存各节点进度。每个国策完成后立即检查所有国家；`on_weekly` 再检查一次，处理后来成为苏联附庸或加入阵营的共产主义国家。符合条件者按已完成节点重建三个动态民族精神的专用变量，并补齐对应机构 idea；失去资格者撤下这三份精神和机构 idea。新成员在全部通用国策完成后入会，也会在最近一次周检获得已完成节点的全部**持续性民族精神**。国策的一次性资源、建筑、经验和外交效果不会追溯发放。旧存档由启动／周检按苏联已完成的节点初始化旗标。

2026-10-02 补齐后来加入者的国策进度：对实际挂载通用线且符合成员资格的国家，按苏联进度旗标逐节点执行 `unlock_national_focus`，仅跳过尚未完成的节点，包括入口。该原版效果将节点视为完成但不执行完成奖励；持续数值和机构仍由上述统一重建，避免重复发放一次性奖励及递归触发补发。失去资格只撤下持续奖励，不抹除已经完成的国策状态。
