## 1. 要出的图（共 6 张）

> ⭐ **本批的特殊之处：他是一个「靠一双手吃饭、靠一张嘴替一群人说话」的人。**
> 所以整条线的视觉母题是 **「一双手与它争到的那一句话」** ——
> **排字盘上的铅字 / 石印石上的墨 / 一城一国会场的木椅 / 一排挡在门前的肩膀 / 一叠没有念出去的稿纸 / 一个名字的一行墨迹**。
> 📌 **入口图标的引导词早就定好了**（`docs/28` §89）：
> 「**工会会徽 / 一群背对镜头的工人侧影 / 车间与齿轮**」—— 本批与之同一套语言（**手 + 车间 + 会场的椅子**）。

### ⚠️ 整条线的视觉注意事项

1. **母题只有一件事：一双手在纸与铁之间做工，最后把该说的话咽回去。** 本批的关键词是：
   **铅字与排字盘 / 石印石与墨辊 / 一排木椅与代表席 / 挡在门前的肩膀 / 没有念出的稿纸 / 一行不可辨认的墨迹**。
   与已完成批次明确区分开：

   | 批次 | 母题 |
   | --- | --- |
   | 李可夫（`docs/31`） | 工业、机构、供给线 |
   | 季诺维也夫（`docs/34`） | 国际、会场、东方人群 |
   | 加米涅夫（`docs/37`） | 手稿、档案、书与印刷 |
   | 斯米尔诺夫（`docs/40`） | 河、铁轨、雪原、界线 |
   | 谢列布里亚科夫（`docs/43`） | 营房、汇聚的线、道岔、公路、车床 |
   | 普列奥布拉任斯基（`docs/46`） | 账簿、秤与剪刀、统计曲线、从田野到工厂的资源流 |
   | 拉狄克（`docs/49`） | 越境的地图线、地下印刷品的墨、铁窗光影、街垒、课桌、一支笔 |
   | 斯米尔加（`docs/52`） | 冰海航路、矿灯与煤、方格网、计算尺与挂图、图网上的圆点、一道缝 |
   | **托姆斯基（本批）** | **排字盘上的铅字、石印石与墨辊、一排木椅的代表席、挡在门前的肩膀、没有念出的稿纸、一个名字的一行墨迹** |

   🚩 **最容易混的三批 —— 本批的关键难点**：
   ① **与加米涅夫那批（`docs/37`）—— 最危险的一个**：
      他那批是「**保存下来的东西**」（**合上的书、档案柜、书脊、装帧、成套的卷册**）；
      本批是「**正在做的活计**」（**排字盘上的散字、石印石、墨辊、油污的手**）。
      ⭐ **一句话区分**：**他画的是「已经印好的书」，本批画的是「还没印出来的那一行字」**。
      ⛔ **本批不要出现合上的书、书脊、书架、档案柜、装帧皮面**。
   ② **与拉狄克那批（`docs/49`）**：他那批的墨是**地下印刷品的墨**（**外面**，越境、铁窗、街垒）；
      本批的墨是**自己这一行的墨**（**厂里**，排字房、石印车间）。
      ⭐ **区分**：**他是「把字送到墙外去」，本批是「把字挣成一份合同」**。
      ⛔ **本批不要出现铁窗光影、街垒、地图上的国界线、一支蘸水笔**。
   ③ **与季诺维也夫那批（`docs/34`）**：他那批的会场是**共产国际的大会场**
      （**多国旗帜、大讲台、东方人群、语言各异的代表**）；
      本批的会场是**本国工会的代表席**（**一排排同样的木椅、本国工人的背影、车间味的会场**）。
      ⭐ **区分**：**他画的是「向外的会场」，本批画的是「向内的会场」**。
      ⛔ **本批不要出现地球仪、外国旗帜、多语言标语**。

2. **六张是一条「从车间到会场、最后收在一张纸上」的链**，顺序本身有意义：
   **排字房（1906） → 街上的纵队与联络（1917） → 一排排代表席（1918） → 一排挡在门前的肩膀（1920） → 一叠没有念出去的稿纸（1921） → 一个名字的一行墨迹（结局）**。
   出图时请**按顺序看一遍**：**前三张是「把摊子铺开」，第四张是「顶住」，第五张忽然安静下来，第六张回到一张纸上** ——
   这个节奏是故意的（**他一生都在做前五张，第六张是这一切的来处**）。

   ⭐ **首尾呼应的提示**：**A1 是一块排字盘、E1 是一行墨迹** ——
   **两块都是一张纸上的字**，可以互为呼应（A1 是**手里正在排的字**，E1 是**已经写在自己身上的那个名字**）。

3. **E1 是结尾，构图应最饱满**（照前几批 E1 的处理）—— 它是全线的最后一个节点，
   **五个前置全完成**后才开。

4. 🚩🚩 **画面里绝对不要出现枪、不要出现死亡、不要出现任何自戕的暗示** ——
   E1 收束的是**「他从流放地逃出来时给自己起的那个名字」**，
   **不是他 1936 年的结局**（`docs/54` §4 / `docs/53` §7.2 已写死）。**这是本批唯一的硬性禁区。**

5. 🚩 **画面里不要出现可辨认的文字或数字**（`docs/24` §1）——
   排字盘、稿纸、会场的横幅、厂牌上可以有条纹、横格、色块与铅字的方块，但**不要写出可辨认的字母、汉字、具体数字或地名**。
   ⭐ **本批尤其要小心**：排字盘上的铅字**只画成一个个小小的方块（反字），一块也不要可读**。

6. ✅ **本批没有互斥项、没有成对图**（本线是单线）—— 6 张是一体的。

7. ⚠️ **不要画人脸、不要画人物肖像**（本批走苏联国策图标式）——
   需要「人」时用**手 / 背影 / 剪影 / 一排背影**，不要五官。
