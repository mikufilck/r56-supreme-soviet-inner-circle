### 1.2 🚩 用户裁决：**删掉 A2（伊尔库茨克省）** —— 为什么这个删法是对的

原 A2 的产物是「**一个能落地的省**」（1918 副主席 → 1919 省执委会主席 → 1920–21 省党委主席团主席）。
**删掉它有两个理由**：

| 理由 | 说明 |
| --- | --- |
| ① **它与斯米尔诺夫（Idx 6）的西伯利亚题重叠** | `docs/56` §2.3：斯米尔诺夫的主线就是「**把俄罗斯的东部边地一块块造成苏维埃国家的一部分**」（斯维亚日斯克 → 西伯利亚革命委员会 → 远东共和国），而伊尔库茨克正在那片地理里 |
| ② **入口不靠它** | A1 到它需要「**建政失败逃回来**」来连接 —— **而 A1 到新的 A2（《红星报》）不靠任何外部事件**：**一份杂志 → 一张报纸，换的只是载体的等级** |

⭐ **删掉之后主干反而更干净**：**四个载体全部是「字出得来的地方」**（杂志 / 报纸 / 摄影棚 / 手抄稿），
**没有一个需要额外解释**。

> 📌 **同时移出的还有它的官衔**（`docs/43` 的先例「砍枝时官衔链也要一并移出那个领域」——**第 3 次**）：
> ⛔ **「伊尔库茨克省执行委员会主席」（1919）不再是 Lv2**，见 §4。

### 5.1 ⭐⭐ 标题与文案是同一个主题的两面（本线的设计要点）

**E1 的标题是「上留京诺的留京」**（他的姓 = 他出生那个村的名字），
**E1 的文案是他在笔录上拒绝认罪的那句**（他没有在控告书上签字）。

> ⭐ **两件事都是关于【名字】的**：**名字是村名给的，而他到最后也没有在别人的纸上签下那个名字。**
> 📌 与托姆斯基（Idx 11）那轮同型：**他的标题是逃亡路上给自己起的化名，文案是他给自己定的坐标** ——
> **两条线的 E1 都是「一个人自己给自己定位置」，但一个用「名字」，一个用「名字 + 不签字」。**

### 5.2 ⚠️ 本节的**两个欠缺，要如实说**

**① A4 的文案只用了纲领的【后半句】**
原文是「**结束强行集体化（与农民讲和），放缓实行工业化，恢复之前开除出党的人的党籍（包括托洛茨基）并「重新开始」**」
—— ⛔ **前半句（农业 + 放缓工业化）是布哈林 / 李可夫的题**，本线**只取后半句**。
📌 **这不是「掐头去尾」，而是「这句里有一半不属于这条线」** —— 文档里如实标注。

**② E1 是「英译再中译」**
俄文原文未找到（`[W]` en 只给英译）→ 按**斯米尔加 / 谢列布里亚科夫那几轮的先例**处理：
**中译稿 + 标注待复核**（进 `docs/99` §十八）。
