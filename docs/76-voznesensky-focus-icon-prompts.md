## 2. 全线视觉母题：**「一台会算数的机器，和它算出来的东西」**

⭐⭐ 本线讲的不是「他下了什么命令」，而是「**一个数字是怎么被算出来、又怎么变成命令的**」——
所以六张图的母题是**那台手摇计算器**（**它出现在每一张里，但每次都比上一次小/退后**）
**＋它算出来的那个东西的实物形态**（稿纸 → 一座城 → 一排桌子 → 一排箱子 → 一排弹壳 → 一本书）。

| 母题 | 出现位置 | 含义 |
| --- | --- | --- |
| ⭐⭐⭐ **手摇计算器**（**黑漆机身 + 黄铜摇柄 + 一排数字轮**） | **#1 #2 #3 #4 #6**（**#5 只在最前**） | ⭐ **本线唯一的贯穿物** —— 「拿得出多少」这句话的**工具** |
| ⭐⭐⭐ **「一排等距的东西」** | **#3 #4 #5** | ⭐ **这是本线的【尺度轴】**：一排桌子 → 一排箱子 → 一排弹壳，**东西越来越大、越来越硬** |
| ⭐⭐ **「压在上面」** | **#1 #6** | 首尾：**#1 是计算器压着稿纸，#6 是计算器压着一本书** —— **同一个人、同一台机器，一头是主张，一头是结论** |
| ⭐ **摇柄的三种位置** | **#1 半途 · #4 转到底 · #6 归位** | ⭐ **「还在算 / 算完了 / 算完之后」** |

### 2.1 ⭐⭐ 一句话记法

> **别人画的是「他决定了什么」，本线画的是「那个数字是什么时候变成一个东西的」。**

### 2.2 色调（照 `docs/23` **判据 G** —— 色调只能来自画面里那个物体本身的颜色）

| # | 色调 | 这个色属于画面里的哪个物体 |
| --- | --- | --- |
| 1 | 稿纸的**旧纸黄** + 机身的**黑漆** + 摇柄的**黄铜** | 稿纸 / 计算器 |
| 2 | 厂房剪影的**冷钢灰**（越远越浅）+ 计算器的黑 | 厂房 / 计算器 |
| 3 | **一排计算器的金属冷灰**（向纵深递浅，最后几台几乎并入背景） | 那一排计算器本身 |
| 4 | 板条箱的**原木黄**与**草绳的土褐** | 箱子 / 绳子 |
| 5 | 弹壳的**黄铜**（唯一的暖金，且是画面里最亮的东西） | 弹壳本身 |
| 6 | 硬封的**深墨绿** + 压印的**暗金** + 计算器的黑 | 书 / 计算器 |

> 🚩 **六张连起来是一条「黑 → 冷灰 → 木黄 → 黄铜 → 墨绿」的曲线**，但**每一处颜色都能指回一个物体** —— 符合判据 G。
> ⛔ **不许给整张图上色**（不画整幅冷蓝夜景、不画整幅青绿）。
