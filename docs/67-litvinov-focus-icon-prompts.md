## 2. 全线视觉母题：**「一条线」**

⭐⭐ 本线讲的不是「他在国内做了什么」，而是「**墙里与墙外**」——
所以六张图的母题是**「一条被跨过去 / 被划出来的线」**，**不是文件堆、不是会议室、不是勋章**。

| 母题 | 出现位置 | 含义 |
| --- | --- | --- |
| ⭐⭐ **国境线**（一堵墙的墙头） | **#1** | 他把一件东西从线的外面送进里面 |
| ⭐⭐ **桌子中间那条线** | **#2** | 两个人（两方）第一次坐到同一条线的两侧 |
| ⭐⭐ **签名线** | **#3** | 一条线上排着几个名字 —— **多边**的意思全在这排线上 |
| ⭐⭐⭐ **刻度线** | **#4** | **定义 = 一把尺子**（本线唯一一件「工具」） |
| ⭐⭐ **连接线** | **#5** | 两国之间被连起来；**那一小页纸是链子上的环** |
| ⭐ **行程线** | **#6** | 他还在路上 —— 车票与箱子 |

> 🚩 **与三条已实装线的区分（他排掉 0 人，21 人全能同席，所以必须写死）**：
> | 线 | 它的母题 | 本线 |
> | --- | --- | --- |
> | **施利亚普尼科夫（Idx 13）** | **「制度的物证」** —— 账本 / 名单 / 计划表 / 抽屉 | ⛔ **本线不画账本、不画名单、不画格子表、不画抽屉** |
> | **加里宁（Idx 14）** | **「一张被翻开的纸 + 一道被走过的门」** | ⛔ **本线不画门、不画门槛、不画信** |
> | **里亚京（Idx 12）** | **「一叠纸的五种大小」**（薄杂志 / 报纸 / 摄影棚 / 手抄稿 / 笔录） | ⛔ **本线不画印刷品、不画报纸版式、不画打字机** |

| ⛔ **莫斯科审判 / 布哈林 / 李可夫** | 🔴🔴 **他被任命进那个决定布哈林与李可夫命运的委员会**，但**这两人是本 mod 已实装的本人** |

| ⛔ **他的死（1951-12-31）与「是否被谋杀」** | **两说并存**（米高扬说卡车撞车 / 家属说心脏病）→ 不做 |
| ⛔ **「他以犹太人身份被撤」** | 族裔一个字都不进游戏（`docs/65` §8.4） |
| ⛔ **共产国际 / 德共 / 中山大学 / 中国革命** | 季诺维也夫（Idx 4）· 拉狄克（Idx 9）· 托洛茨基（Idx 1）的题 |
