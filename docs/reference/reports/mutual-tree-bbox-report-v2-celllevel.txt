=== 旧版错在哪 ===
旧报告 mutual-tree-bbox-report.txt 由 build/../docs/reference/tools/scan-mutual-tree-bbox.ps1 生成。
它把文件里【所有】`x = <数>` 行都算进了包围盒 —— 包括 focus 块内部的
`offset = { x = … }` / `initial_show_position = { x = … }` 等，于是 X 最大被抬高
（如 norwegian_focus 旧 94 / 实测 20）；而个别树反而偏小（french_focus 20 / 实测 67），
说明它还有别的解析缺口。
⇒ ⛔ **该脚本的读数不要再用于选址**。要用就改成「brace-match 只取 focus_tree 下一层的 focus 块」。
📌 S5 v7 的对策是【彻底不用这张表】—— 带子放在所有树下方，不做逐国微调。
