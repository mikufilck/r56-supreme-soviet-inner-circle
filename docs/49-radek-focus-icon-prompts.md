## 1. 要出的图（共 6 张）

> ⭐ **本批的特殊之处：他是一个办报的报人，而他那条线的题目是「把革命办到俄国以外」。**
> 所以整条线的视觉母题是 **「越境与文字」** ——
> **一张摊开的地图 / 一份地下传单 / 铁窗的光 / 熄灯的街垒 / 一排异国学员的课桌 / 一支笔**。
> 📌 **入口图标的引导词早就定好了**（`docs/28` §82）：
> 「**共产国际的旗；报纸与喇叭；谈判桌与条约**」—— 本批与之同一套语言（都带「往外说」的性质）。

### ⚠️ 整条线的视觉注意事项

1. **母题只有一件事：把文字送出国境。** 本批的关键词是：
   **越境的线 / 地下印刷的墨 / 铁窗的影子 / 未点亮的街灯 / 东方学员的课桌 / 笔尖上的红墨**。
   与已完成批次明确区分开：

   | 批次 | 母题 |
   | --- | --- |
   | 李可夫（`docs/31`） | 工业、机构、供给线 |
   | 季诺维也夫（`docs/34`） | 国际、会场、东方人群 |
   | 加米涅夫（`docs/37`） | 手稿、档案、书与印刷 |
   | 斯米尔诺夫（`docs/40`） | 河、铁轨、雪原、界线 |
   | 谢列布里亚科夫（`docs/43`） | 营房、汇聚的线、道岔、公路、车床 |
   | 普列奥布拉任斯基（`docs/46`） | 账簿、秤与剪刀、统计曲线、从田野到工厂的资源流 |
   | **拉狄克（本批）** | **越境的地图线、地下印刷品的墨、铁窗光影、街垒、课桌、一支笔** |

   🚩 **最容易混的两批**：
   ① **与加米涅夫那批**：他那批的纸是**被收藏、被整理、被印刷的纸**（档案柜、全集书脊、印刷机 —— **纸的静止状态**）；
      本批的纸是**被写、被偷运、被散发的纸**（传单、小册子、笔尖 —— **纸在行动**）。
      ⛔ **本批不要出现档案柜、书脊墙、印刷机与装订线**。
   ② **与季诺维也夫那批**：他那批是**宏大的、公开的国际会场**（万人大会、旗帜如林、东方人群）；
      本批的会场是**秘密的、昏暗的、人少的**（地下状态，**有被发现的危险感**）——
      A5 更不是会场，而是**一间教室**。
      ⛔ **本批不要画旗林与万人场面**。

2. **六张是一条「由近及远、再折回自身」的链**，顺序本身有意义：
   **摊开的地图（1918） → 昏暗的地下会场（1918） → 铁窗下的七本小册子（1919） → 熄了灯的街垒（1923） → 异国的课桌（1925） → 一支笔（结局）**。
   出图时请**按顺序看一遍**：**前四张都在「境外」且色调越来越冷、越来越暗，第五张突然到了室内、有了人气，第六张收回到桌面上的方寸之地** ——
   这个节奏是故意的（**他的一生都在往外送东西，最后剩下的只有那支笔**）。

3. **E1 是结尾，构图应最饱满**（照前几批 E1 的处理）—— 它是全线的最后一个节点，
   **五个前置全完成**后才开。⭐ 它与 A1 是同一张桌子的两面（**从写给外人看，到只剩下自己写**）。

4. 🚩 **画面里不要出现可辨认的文字或数字**（`docs/24` §1）——
   报纸、传单、地图、黑板上可以有条纹、横格、色块与图例方框，但**不要写出可辨认的字母、汉字、具体数字或国名**。

5. ✅ **本批没有互斥项、没有成对图**（本线是单线）—— 6 张是一体的。

6. ⚠️ **不要画人脸、不要画人物肖像**（本批走苏联国策图标式）——
   需要「人」时用**手 / 背影 / 剪影 / 一排背影**，不要五官。

## 2. 整条线的视觉小结

| 顺 | 图 | 主体 | 性质 | 色调 |
| --- | --- | --- | --- | --- |
| A1 | 外交人民委员部中欧司 | **摊开的中欧地图 + 外伸的线路 + 印章与笔** | 公务（静） | 冷灰蓝 + 米黄 |
| A2 | 德国共产党的第一次代表大会 | **地下会场 + 煤油灯 + 一叠传单** | 秘密（暗） | 暗棕 + 暖黄 |
| A3 | 狱中的七本小册子 | **铁窗的光 + 并排的七本薄册子** | 受限（冷） | 冷灰 + 一道光 |
| A4 | 德国十月 | **半成品的街垒 + 熄掉的街灯** | 退却（夜） | 冷蓝夜 + 昏黄 |
| A5 | 中山大学 | **阶梯教室 + 课桌 + 讲台上的背影** | **转向（亮）** | 暖木色 + 粉笔白 |
| E1 | 红色笔杆子 | **一支钢笔压在几叠报纸上** | **收束回方寸（最大的一张）** | 暖褐 + 报纸灰白 + 一处红 |

**一条链的三个变化**：
1. **空间**：**地图（A1）→ 地下（A2）→ 牢房（A3）→ 街头（A4）→ 室内（A5）→ 桌面（E1）**
   —— 从**越铺越大的地图**，一路收到**一张桌面**
2. **明暗**：公务的冷（A1）→ 越来越暗（A2）→ 最冷最暗（A3）→ 夜（A4）→ **突然转亮（A5）** → 温暖的收束（E1）
   （**A5 的「亮」是故意的**：它是全线唯一一次「结果看得见」的时刻）
3. **方向**：**向西 ×4（A1–A4）→ 转向东 ×1（A5）→ 折回自身 ×1（E1）**
   —— 与史实一致：1918–1923 他都在德国，1925 起换到东方，而他一辈子真正没变的是那支笔
