## 2. 全线视觉母题：**制度的物证**

⭐⭐ **第三版换了母题** —— v1 用过「卡尺与车床」（车工身份的隐喻）、v2 用过「工作台上的零件与工牌」（现场物件），
**两者都随主干一起废掉**。第三版的母题是**「纸上有字的东西」**与**「门口」**；
**第四版删掉「机关里坐着谁」之后，「门口」这个母题只剩一处**（见下表）。

| 母题 | 出现位置 | 含义 |
| --- | --- | --- |
| ⭐⭐ **有格子的纸**（账本 / 计划表 / 界线 / 名单 / 抽屉 / 日历） | **#1 #2 #3 #4 #5 #6**（**六张全有**） | **制度本身就是纸上的东西** —— 本线讲的是**规则怎么定**，不是**车间里发生了什么** |
| ⭐ **一张纸分成两半** | **#2 #4** | **划线**与**两条去路** —— 本线最锋利的两个动作都用「分半」表达 |
| ⭐ **工帽与深色外套** | **#3 #4 #6** | **「干活的人」的统一记号** —— 只要画面出现一群人，就戴工帽 |
| ⭐ **入口 / 门** | **#4**（递进车间那一半） | ⚠️ **第四版之后只剩这一处** —— 原 #2「机关门口两个戴工帽的背影」已随该节点删除 |

> 🚩 **与托姆斯基的区分（`docs/28` §93 的约定）**：
> **他 = 制度的物证（账本 / 名单 / 计划表 / 抽屉）**；**托姆斯基 = 工会主席的会旗与讲台**。
> 📌 两人的图标**不要出现同一种道具**。
> ⛔ **另两处硬性区分**：**不画厂门口站住的一群人**（那是 v2 的废案，也靠近 1905 年）；**不画车间里的车床特写**（那是 v1 的废案）。

## 5. 🚩🚩 禁区（写死）

| 禁区 | 原因 |
| --- | --- |
| ⛔ **不画没收 / 查封 / 封条 / 枪**（#1） | 「工人监督」讲的是**控制权**，不是**没收** —— 那是后来国有化才做的事 |
| ⛔ **不画办公室内景 / 不画公文**（#5） | #5 要的是「**他离开办公室回到车间**」—— 一离开就不能画内部 |
| ⛔ **不画西装革履的议会**（#3） | 那是「议会」，不是**生产者代表大会** —— **代表得戴工帽** |
| ⛔ **不画机关门口站住的一群人**（全篇） | ⚠️ **第四版新增** —— 原 #2「机关里坐着谁」的意象**已随节点删除**，不要再用别的方式画回来 |
| ⛔ **不画厂门口站住的一群人**（全篇） | 那是 v2 的废案（「穆罗姆的街头」），且靠近 1905 年 |
| ⛔ **不画车间里的车床特写**（全篇） | 那是 v1 的废案（「卡尺与车床」）；#5 用**车床旁的工具架**，**不是车床本身** |
| ⛔ **不画 1937 年、不画刑场、不画铁窗、不画审讯**（全篇） | **原版两处集团释放已经占了「把他放出来」这个题**；且这是里亚京（Idx 12）刚用过的禁区（`docs/58` §5） |
| ⛔ **不画「工会会旗 / 讲台」** | 那是托姆斯基的（`docs/28` §93） |
| ⛔ **不出现可辨识的文字** | 账本 / 名单 / 计划表 / 日历 / 铭牌一律用**抽象纹样**（避免与简中本地化冲突） |
