## §1 母题 = **「纸上的东西，和它落到地上变成的东西」**

⭐ **本线所有画面都是【纸 / 牌子 / 章 / 名单 / 条例】**，**没有一张是战场**。
⭐ 主干 =「**他把一摊事，变成一个交出去也能自己走的机关**」—— 别人带兵，他建机关。
→ 所以画面里**出现的是机关留下的物证**（一本花名册、一枚胸章、一叠肩章、一张联络图、一本账、一份文件），**不是打仗的场面**。

### §1.1 六张图的母题

| # | 画面 | 色调（**判据 G**） |
| --- | --- | --- |
| **A1** | 一条**长凳**上摆着一顶**军帽**、一件叠好的**军大衣**，旁边一本**摊开的笔记本** | 军装的**灰绿褐** + 纸的**黄**（**来自军帽、军大衣、笔记本**） |
| **A2** | 一枚**胸章**挂在一件旧**棉袄**的前襟上，别针**还没扣好** | **珐琅红** + 布的**灰**（**来自胸章、棉袄**） |
| **A3** | 一叠**肩章**摊在**桌布**上，边上压着一本**花名册** | 金属**金** + 布**蓝**（**来自肩章、桌布**） |

## §2 硬性禁区（18 条）

⛔ **全篇不画**：**1937 年 / 逮捕 / 刑场 / 铁窗 / 枪决 / 血**
⛔ **全篇不画**：**克里姆林宫 / 红场 / 列宁墓 / 莫斯科地标**
⛔ **不画战场**：战壕 / 炮火 / 冲锋 / 坦克冲锋 / 骑兵冲锋（**本线一个战斗节点都没有**）
⛔ **不画海军**：军舰 / 水兵 / 港口（彼得·斯米尔诺夫 Idx 19 的领域）
⛔ **不出现斯大林的形象 / 侧影 / 背影 / 照片**
⛔ **不画列宁格勒 / 芬兰 / 喀琅施塔得**
⛔ **不画纪念像 / 雕像 / 半身像 / 纪念碑基座**
> —— ⭐ 这一条是本线**最重要**的禁区：**「一个活着的、有名字的纪念碑」是本线要避免的读法**（`docs/86` §0.7）。
⛔ **不画地图上的城市改名 / 路牌上写着他姓氏**
⛔ **不画他本人**（本项目所有个人线都不出现真人）
⛔ **A1 不画**：讲台 / 主席台 / 勋章 / 阅兵
⛔ **A2 不画**：靶场 / 举手枪的人 / 军械库
⛔ **A3 不画**：元帅星 / 大檐帽特写 / 授衔仪式
⛔ **A4 不画**：森林里的游击队 / 埋炸药 / 铁路破坏
⛔ **A5 不画**：被缴获的德军装备特写 / 万字旗 / 战俘
⛔ **E1 不画**：德国 / 柏林 / 万字旗 / 投降签字仪式的长桌（**那是原方案「无条件投降文件」的画面，已作废**）
⛔ **E1 不画**：四国国旗并排（会读成「波茨坦」）
⛔ **判据 G**：⛔ **不给整张图上一遍色**（历史事故：拉狄克 `german_october` 整幅冷蓝夜景 70.5 %、斯米尔加 `productive_forces` 整幅青绿 48.5 %）
⛔ **不画**：西装革履的会议室 · 打字机特写 · 报纸头版（**判据 A：这些是别人的隐喻**）

## §3 六张图的完整提示词

### A1 · 工农红军指挥员（`hof_ic_voroshilov_the_red_army_commanders`）
> **物件**：一条**长凳**，上面摆着一顶**军帽**（红星帽徽朝上）、一件叠好的**军大衣**，旁边一本**摊开的笔记本**（页面上是潦草的横线，不是字）。
> **构图**：正面平视，长凳占画面下三分之二，墙上**没有挂图**（**空墙就是「还没有体系」**）。
> **色调**：军装的灰绿褐 + 纸的黄 —— **这两个色都来自画面里的实物**。
> **禁**：不画人、不画讲台、不画勋章、不画阅兵。

### A2 · 伏罗希洛夫射手（`hof_ic_voroshilov_the_marksmanship_badge`）
> **物件**：一枚**胸章**（圆形，红地，中间一个白色靶环图案）挂在一件旧**棉袄**的前襟上，**别针还没扣好**，棉袄有补丁。
> **构图**：近景特写，胸章占画面中心偏上；背景是模糊的灰墙。
> **色调**：珐琅红（胸章面）+ 布灰（棉袄）—— **点题：一枚胸章就是一套考核**。
> **禁**：不画靶场、不画举手枪的人、不画军械库。

### A3 · 个人军衔制（`hof_ic_voroshilov_the_ranks`）
> **物件**：**五副肩章**摊在**桌布**上（**五**这个数是点题：首批五位元帅），边上压着一本**翻开的花名册**。
> **构图**：俯视四分之三，桌面占满画面，桌布有折痕。
> **色调**：金属金（肩章星与边）+ 布蓝（桌布）—— **来自肩章与桌布**。
> **禁**：不画元帅星特写、不画大檐帽、不画授衔仪式、不画真人。

### A4 · 中央游击运动总参谋部（`hof_ic_voroshilov_the_partisan_staff`）
> **物件**：一间**低矮木屋**的内景，一盏**油灯**下摊着一张**手绘的联络图**（只有线和点，没有字），图边压着一支铅笔与一把尺。
> **构图**：微俯视，油灯在左上，图占画面中心。
> **色调**：油灯的黄油褐（**来自油灯与木墙**）—— 只给灯和木墙，**不给整张图上色**。
> **禁**：不画森林里的游击队、不画埋炸药、不画铁路破坏、不画人。

### A5 · 战利品机关条例（`hof_ic_voroshilov_war_trophies_regulation`）
> **物件**：一列**敞车**上堆着**黄铜弹壳**（堆成小山），车边有人拿着**账本**在核对（**人只出手与账本，不给脸**），地上摊着一份**带格的清单**。
> **构图**：侧面平视，车厢占画面上三分之二，账本在下三分之一。
> **色调**：黄铜金（弹壳）+ 铁锈褐（车厢）—— **来自弹壳与车厢**。
> **禁**：不画被缴获的德军装备特写、不画万字旗、不画战俘。

### E1 · 盟国管制委员会（`hof_ic_voroshilov_the_allied_control_commission`）
> **物件**：一张**长条桌**，桌上摊开一份**文件**，压着一支**钢笔**；桌尽头一扇**开着的窗**，窗外是一排**异国的屋瓦**（不是德国 —— 那是匈牙利，但**画面上不要任何国旗或文字**）；墙上有**一块空白的牌子**（**牌子还没有字**）。
> **构图**：正面纵深，长桌从画面前方引向窗口。
> **色调**：冷灰（墙）+ 纸白（文件）+ 屋瓦的暗砖红（**来自墙、文件、屋瓦**）。
> **禁**：不画德国 / 柏林 / 万字旗、不画投降签字仪式的长桌、不画四国国旗并排。
