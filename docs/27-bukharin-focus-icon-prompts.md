## 1. 要出的图（共 9 张）

### 支线 A · 过渡期与 NEP（3 张）

#### A1 · 过渡时期的经济
| 项 | 内容 |
| --- | --- |
| **sprite** | `GFX_hof_ic_bukharin_economics_of_transition` |
| **效果** | 科研速度 **+5%**；稳定度 **+5%** |
| **文案（节选）** | 「这种联盟的路线是过渡时期全部政策的**实质**。因为过渡时期最明显的特点主要是两阶级社会，在这样的社会里，城市和农村、工业和农业、大生产和小生产、合理的计划和无政府主义的市场等等问题表现了主要的**阶级问题**，即工人阶级和农民之间的相互关系问题。」 |
| **意象引导（可选）** | 过渡/未完成的桥、半农业半工业的两半景象 |

#### A2 · 新经济政策不是退却
| 项 | 内容 |
| --- | --- |
| **sprite** | `GFX_hof_ic_bukharin_nep_is_not_a_retreat` |
| **效果** | 消费品工厂占比 **−5%**；政治点获取 **+5%**；建筑建造速度 **+5%** |
| **文案（节选）** | 「或者我们在过渡时期要建立无产阶级领导下的工农联盟，那么，这条路线应当是我们各种活动的基本原则。」 |
| **意象引导（可选）** | 向前的道路、行进中的队列（"不是退却"） |

#### A3 · 取消「贡款」
| 项 | 内容 |
| --- | --- |
| **sprite** | `GFX_hof_ic_bukharin_abolish_the_tribute` |
| **效果** | 稳定度 **+10%**；每日共产主义支持度 **+0.02**；**政治点获取 −5%** |
| **文案（节选）** | 「无产阶级不是农民的剥削者，也不可能是农民的剥削者。请取消您的『贡款』，哪怕作为失言也罢！……**贡款**是非常明确的历史范畴，它同社会主义毫无共同之处，也不可能有共同之处！不能这样轻率地对待理论观点。**这是无知，是有害的！**」 |
| **意象引导（可选）** | 被划掉的征缴单据／绳索被割断（但线条要克制，不要血腥） |

> ⚠️ **A3 是全线唯一同时带正负效果的国策** —— 农民支持换政治代价。图标可以稍显"对抗"。

### 支线 B · 工农关系与平衡增长（4 张）

#### B1 · 工农联盟是轴心
| 项 | 内容 |
| --- | --- |
| **sprite** | `GFX_hof_ic_bukharin_alliance_is_the_axis` |
| **效果** | 稳定度 **+5%**；每日共产主义支持度 **+0.02** |
| **文案（节选）** | 「在上次辩论中提出的零散的问题……这一切现在都归结为某些基本的方面……而所有这些本身极重大的问题所围绕的**轴心就是工农联盟问题**。」 |
| **意象引导（可选）** | 轮轴／纺轮的圆心、两手相握 |

#### B2 · 发财吧
| 项 | 内容 |
| --- | --- |
| **sprite** | `GFX_hof_ic_bukharin_enrich_yourselves` |
| **效果** | 消费品工厂占比 **−5%**；稳定度 **+5%** |
| **文案（节选）** | 「我们农村政策的发展趋势应当是，要放宽妨碍富裕农民和富农经济发展的许多限制，有一部分甚至要废除。应当向农民，向全体农民说：**发财吧！发展自己的经济吧！**用不着担心，不会有人无情地欺负你们！」 |
| **意象引导（可选）** | 麦穗与锤子并列、丰产的谷仓（**不要画钱币** —— 这句子是鼓励生产，不是鼓励货币） |

#### B3 · 按比例发展
| 项 | 内容 |
| --- | --- |
| **sprite** | `GFX_hof_ic_bukharin_proportional_development` |
| **效果** | 工厂产出 **+5%**；科研速度 **+5%** |
| **文案（节选）** | 「价值规律在消亡。但**按比例的劳动消耗规律**仍存在。……要跳出这一规律是绝对不行的。」 |
| **意象引导（可选）** | 天平两侧分别是齿轮与麦穗、等分的圆环 |

#### B4 · 合作社长入
| 项 | 内容 |
| --- | --- |
| **sprite** | `GFX_hof_ic_bukharin_cooperatives_into_the_system` |
| **效果** | 稳定度 **+5%**；建筑建造速度 **+5%**；消费品工厂占比 **−5%** |
| **文案（节选，一手）** | 「我国基本的农民合作社组织网将不是由富农式的而是『劳动』式的基层合作社细胞构成，**这些细胞将长入到体系中去**。」（接）「另一方面，**富农合作社的窝巢也将会通过银行等等同样长入到这个体系中去**……」 |
| **意象引导（可选）** | 合作社屋舍与银行建筑相连、小溪汇入大渠 |

> 🚨 **这条原名「富农和平长入」，已改名**（2026-09-15 抓到一手材料后）：
> 那句话是**托洛茨基反对派给他扣的帽子**，他 1929-04-18 在全会上**当众否认**。
> 真实主张是「**合作社长入**」（合作社与银行把农村纳入**国家与合作社机关体系**）。
> 详见 `docs/25` 「重大更正」节。
>
> ⚠️ 效果也跟着改了：原来的「每日共产主义支持度」换成「**建筑建造速度**」——
> 因为他原话明确说富农合作社是「**异物**」（像租让企业），**不是**社会主义成分。
