### §1.4 主干

> ⭐⭐⭐⭐⭐ **主干 =「他把一摊事，变成一个交出去也能自己走的机关」**
> ⭐ 一句话：**别人带兵，他建机关 —— 而那些机关里，有的直接就叫他的名字。**

**为什么是他独一份（判据 B）**：把「军事首长」这个职业换任何一个人来，这条轴都不成立 ——
- **托洛茨基建的是军队本身**（缔造红军 5 块）
- **图哈切夫斯基建的是条令**（把构想写进野战条令）
- **彼得·斯米尔诺夫建的是海军部**（一个「部」）
- **斯米尔加建的是计划机关**（计委）
- ⭐ **只有他的产物横跨「国防体育（靶章 / 越野赛）→ 军衔制度 → 游击战机关 → 战利品机关 → 受降文件」** —— **五件东西分属五个完全不同的领域，但都是同一件事：把一摊混乱写成一份能发下去的东西。**

**判据 C（产物抬到国家制度层）**：
- 「伏罗希洛夫射手」= **全国的国防体育考核制度**（数百万青年考这个证）
- 「伏罗希洛夫越野赛」= **全国性的群众体育**
- 个人军衔制 = **一套沿用至苏联解体的军衔制度**
- 中央游击运动总参谋部 = **沿用至战争结束的国家机关**
- 《红军战利品机关条例》= **红军的战利品机关编制**
- 《德国无条件投降文件》= **让一个国家交出自己的文件**

**判据 A（隐喻层）**：与已实装 21 条全部不撞（见 §6）。

### §1.5 推论（从主干推出，不是拼上去的）

1. **既然是「把一摊事写成一份能发下去的东西」，那么他一生最重要的一步不是任何一场战役，而是「命名」** —— 命令、条例、胸章、军衔表，全是**在纸上给东西定名**
2. **既然是「机关」，那么「他在不在」不重要** —— ⭐ **游击运动总司令这个职位 1942-11-19 被撤销了，但那个机关一直工作到战争结束**（这就是主干最硬的一条实证）
3. **既然是「交出去也能自己走」，那么他自己的位子被撤掉就不奇怪** —— 1940 被撤国防人民委员、1960 被撤主席团主席、1921 被从工会…⚠️ 是他的常态
4. **他的根必须与「名字」有关** —— 因为「命名」是他全部产物的共同动作
   → ⭐ **根 = 1906 年他给自己挑的那个化名**（**他一生唯一一次自己命名自己**）
5. **他不可能是「一线」的** —— ⭐ **判据 C 的反面自检**：他一辈子没打过一场胜仗（朱可夫：「业余爱好者」），所以**本线一个战场节点都没有**

### §1.6 并列要求

⭐ **一条线的产物必须能并排放**（不是拼上去的）。本线五件产物的并列关系：
**「体育考核」→「军衔」→「游击机关」→「战利品机关」→「受降文件」**
—— 从**一个人的考核**，到**一支军队的编制**，到**一支游击队的指挥**，到**一整套后勤机关**，到**一个国家的交出**。
⭐ **尺度是逐级放大的**（人 → 军 → 敌后 → 战利品 → 敌国）。

## §4 聚类成支线

⭐ **用户口径史**：本项目连续 8 轮都取**单线 5 节点 + 1 单结局**（加里宁 / 李维诺夫 / 索柯里尼柯夫 / 图哈切夫斯基 / 沃兹涅先斯基 / 彼得·斯米尔诺夫 / 马林科夫 / 赫鲁晓夫）。
⭐ 本线**没有第二条轴**（他的产物虽然跨五个领域，但**动作是同一个**）→ **单线，不做支线**。

| **A2** | **伏罗希洛夫射手** | 1932-12-29 | ⭐ 一枚胸章 = 一整套全国神枪手考核制度 |

⭐ **时间完全单调递增**（1927 → 1932-12 → 1935-09 → 1942-09 → 1943-04 → 1944-02）。
⭐ **首尾同轴**：**根 = 1906 年他给自己挑的那个化名**（他一生唯一一次自己命名自己）；**E1 = 1944 年他主持的委员会写下的那份文件**（这个名字，决定另一个国家还叫不叫自己的名字）。
—— **首与尾都是「名字」，而中间的五个节点是「名字是怎么被写进一份份东西里的」。**

## §5 跨簇钩子

⭐ **本线不设跨簇钩子。**
理由：单线 5 节点全部在一条轴上，**没有第二簇可以跳**（与加里宁 / 李维诺夫 / 索柯里尼柯夫 / 图哈切夫斯基 / 沃兹涅先斯基 / 彼得·斯米尔诺夫 / 马林科夫 / 赫鲁晓夫那 8 轮同规格）。

⚠️ **但保留一条「弱钩子」备查**（**不实装**）：
**A5（战利品机关条例）→ 匈牙利盟国管制委员会**（1945–1947）—— ⭐ 都是「把一摊战后的东西写成能交出去的形式」。
📌 **不采用**：匈牙利那一段与 A5 在**同一根轴**上（不是跳簇），且时间比 E1 晚。
