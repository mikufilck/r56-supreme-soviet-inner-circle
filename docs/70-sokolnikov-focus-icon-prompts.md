## 2. 全线视觉母题：**「一张纸与一枚币」**

⭐⭐ 本线讲的不是「他做了什么官」，而是「**什么能拿去算**」——
所以六张图的母题是**「纸（票面）与金属（币 / 锭）的并置」**，
**不是账本、不是办公室、不是会场**。

| 母题 | 出现位置 | 含义 |
| --- | --- | --- |
| ⭐⭐ **纸（票面 / 纸带）** | **#1 #2 #3 #4 #6** | 「钱」的**前一半**：印出来的那部分 |
| ⭐⭐ **币（金属）** | **#3 #4 #5 #6** | 「钱」的**后一半**：能拿去称的那部分 |
| ⭐⭐⭐ **币从无到有** | #1 #2 **没有币** → #3 一枚 → #4 两枚 → #5 立起来 → #6 变成铸锭 | ⭐ **六张连起来是一条「金属逐步出现」的曲线** —— 这就是主干的进程 |
| ⭐ **铁柜 / 台面 / 桌面**（承载物） | **#1 #2 #4 #6** | 「算」要有一个平面 —— ⚠️ **是金库与台面，不是办公桌** |
| ⭐ **一处比例**（#3 的四分之一） | **#3** | ⭐ **史实的数字用构图说，不用文字说** |

### 2.1 ⭐⭐ 一句话记法

> **别人画的是「谁在管什么」，本线画的是「什么能拿去算」。**

## 2.2 🚩🚩 色调纪律（2026-09-20 新增 —— 见 `docs/23` **判据 G**）

> **由来**：用户 2026-09-20 问 ——「**最近出的图好像内里都是彩色图画，是因为叙事需要故意为之吗？**」
> 实测（游戏内 DDS，取中心区「**非金 / 非红 / 非中性灰**」的像素占比，即真正的彩色主体）：

| 批次 | 其他色相占比 | 判定 |
| --- | --- | --- |
| 托洛茨基（17 张） | **1.1 %** | ✅ 纯单色 |
| 布哈林（9） | 1.3 % | ✅ |
| 李可夫（5） | 1.1 % | ✅ |
| 季诺维也夫（11） | 0.9 % | ✅ |
| 加米涅夫（5） | 0.9 % | ✅ |
| 斯米尔诺夫（6） | 6.9 % | ✅ 基本纯 |
| 谢列布里亚科夫（5） | 7.2 % | ✅ 基本纯 |
| 普列奥布拉任斯基（5） | 11.9 % | 🟡 开始漂 |
| **拉狄克（6）** | **18.9 %** | 🔴 **明显漂**（单张最高 `german_october` = **70.5 %**） |
| **斯米尔加（6）** | **17.5 %** | 🔴 **明显漂**（单张最高 `productive_forces` = **48.5 %**） |
| 托姆斯基（6） | 5.3 % | ✅ 回正 |
| 里亚京（5） | 9.5 % | 🟡 略漂 |

> **结论：是有意的，但不是「叙事需要」一种解释能盖住的 —— 是两件事叠在一起。**
>
> ① ✅ **明确的设计意图** —— 从 `docs/46` 起，每份出图文档新增一列 **「色调」**；
>    到 `docs/49`（拉狄克）升级成一条**明暗 / 冷暖曲线**：
>    「**前四张都在境外且色调越来越冷、越来越暗，第五张突然到了室内、有了人气，第六张收回到桌面上的方寸之地**」；
>    美术的交付记录（`art/focus/radek/README.md`）也如实写着「**依 MD49 要求，饱和红仅用于结局的笔尖墨水**」。
> ② ❌ **但它偏离了 `docs/24` §2.2 的原始规格** —— 那条写的是
>    「主体是**象牙白 / 石膏灰的单色雕塑质感（不是彩色）**」「**低饱和**」。
>    **这条规格从来没被作废，只是从 `docs/46` 之后没人再引用它** →
>    事实上被后来的「色调」列覆盖，成了**僵尸规格**（违反 `AGENTS.md` 规则 10「单一权威出处」）。
>    📌 **关键证据**：托洛茨基那份（**1.1 %**）与拉狄克那份（**18.9 %**）**用的是同一份规格文本**
>    —— 所以差别**不是规格允许的**，是**执行漂移**。

> ⭐⭐ **判据 G（2026-09-20 提炼）：色调只能来自「画面里那个东西本身的颜色」。**
> - ✅ **合例**：`#3` 的金色来自**那枚金币**；`#1` 的冷灰来自**那扇铁柜门**。
> - ❌ **不合例**：给**整张图**上一遍色 —— 拉狄克 `german_october`（**70.5 %** 整幅冷蓝夜景）、
>   斯米尔加 `productive_forces`（**48.5 %** 整幅青绿）。
> - 📌 **自检**：把画面里的物体逐个念一遍 —— **如果那个色不属于其中任何一个物体，它就超标了。**
> - 🚩 **适用范围**：**只对尚未设计的线生效**（`docs/23` 判据 E 的同一条精神）
>   → ⛔ **已交付的 11 条【不返工】**（它们只是比要求多上了一点色，无害）。
> - 📌 **两条规则的归属**：**判据 A 管「去隐喻层」，判据 C 管「产物抬到国家制度那一层」，
>   判据 F 管「节点名怎么起」，判据 G 管「图怎么上色」。**
