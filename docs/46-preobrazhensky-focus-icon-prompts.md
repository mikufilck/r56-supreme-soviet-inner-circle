## 1. 要出的图（共 5 张）

> ⭐ **本批的特殊之处：他是一个经济学家，而他那条线的题目是「积累从哪里来」。**
> 所以整条线的视觉母题是 **「计量与提取」** ——
> **一叠税单 / 一把剪刀 / 一架天平 / 两条缠绕的曲线 / 从田野流向工厂的河**。
> 📌 **入口图标的引导词早就定好了**（`docs/28` §81）：
> 「被『挤压』的农业（粮食流向工厂）；**账簿与统计图表**」—— 本批与之同一套语言。

### ⚠️ 整条线的视觉注意事项

1. **母题只有一件事：算账与提取。** 本批的关键词是：
   **税单与谷堆 / 张开的剪刀 / 失衡的天平 / 两条绞在一起的曲线 / 田野流向工厂的资源**。
   与已完成批次明确区分开：

   | 批次 | 母题 |
   | --- | --- |
   | 李可夫（`docs/31`） | 工业、机构、供给线 |
   | 季诺维也夫（`docs/34`） | 国际、会场、东方人群 |
   | 加米涅夫（`docs/37`） | 手稿、档案、书与印刷 |
   | 斯米尔诺夫（`docs/40`） | 河、铁轨、雪原、界线 |
   | 谢列布里亚科夫（`docs/43`） | 营房、汇聚的线、道岔、公路、车床 |
   | **普列奥布拉任斯基（本批）** | **账簿、秤与剪刀、统计曲线、从田野到工厂的资源流** |

   🚩 **最容易混的两批**：
   ① **与李可夫那批**：他那批是**工业与供给的实物**（厂房、粮车、飞机）；
      本批是**计量的工具**（账本、秤、剪刀、曲线）—— **一个是东西，一个是算东西的器具**。
   ② **与加米涅夫那批**：他那批是**书、手稿、档案**（纸的质感）；
      本批虽有账本，但**账本只是道具**，画面主体是**动作与关系**（提取、剪、压、缠）。
      ⛔ **本批不要出现书、手稿、印刷机**。

2. **五张是一条「从实物到抽象、再回到实物」的链**，顺序本身有意义：
   **一叠税单与谷堆（1922） → 一把剪刀（1924） → 一架天平（1924） → 两条绞在一起的曲线（1926） → 从田野流向工厂的河（结局）**。
   出图时请**按顺序看一遍**：**前三张是「器具」，第四张突然抽象，第五张又回到实物** ——
   这个节奏是故意的（**他的理论就是把前三个动作形式化成一条规律**）。

3. **E1 是结尾，构图应最饱满**（照前几批 E1 的处理）—— 它是全线的最后一个节点，
   **四个前置全完成**后才开。

4. 🚩 **画面里不要出现可辨认的文字或数字**（`docs/24` §1）——
   账本、税单、图表上可以有条纹、横格与色块，但**不要写出可辨认的字母、汉字或具体数字**。

5. ✅ **本批没有互斥项、没有成对图**（本线是单线）—— 5 张是一体的。

6. ⚠️ **不要画人脸、不要画人物肖像**（本批走苏联国策图标式）——
   需要「人」时用**手 / 背影 / 剪影**，不要五官。

### A1 · 农村政策提纲

| 项 | 内容 |
| --- | --- |
| **sprite** | `GFX_hof_ic_preobrazhensky_agrarian_theses` |
| **史实** | **1922 年 3 月**的提纲《俄共目前农村政策的基本原则》。他说富农与富裕农民是「**新经济关系的总的经济链条上的必要环节**」，但**国家必须向他们比中农贫农更重地征税**，并且「**利用农村中业已开始的资本主义积累过程来增加社会主义积累**」 |
| **效果** | 政治点数 **+5%**；稳定度 **+5%** |
| **文案（中文原文节选）** | 「国家还必须向这一阶层**加重（同中农和贫农相比）征收实物税和货币税**，让它承担更多的社会义务，同时为了不致破坏富农和富裕农民的经济，在可行范围内**利用农村中业已开始的资本主义积累过程来增加社会主义积累**。」 |
| **出处** | ⭐ `[M]` 中文马克思主义文库·《俄共目前农村政策的基本原则》提纲（1922 年 3 月） |
| **意象引导（可选）** | **一叠摊开的税单（只有横格，无可辨认字迹）压在一座矮矮的谷堆上**，旁边露出账本的一角与一支笔；天空是 1922 年那种灰黄的旱色。**土黄 + 暗灰调** |

> 💡 这是全线的「**第一笔账**」—— 画面要**静、沉、有分量**，不要热闹。

## 2. 整条线的视觉小结

| 顺 | 图 | 主体 | 性质 | 色调 |
| --- | --- | --- | --- | --- |
| A1 | 农村政策提纲 | **税单 + 谷堆 + 账本** | 器具（静） | 土黄 + 暗灰 |
| A2 | 压缩剪刀差 | **张开的剪刀 + 两条曲线** | 器具（动） | 铁灰 + 锈红 |
| A3 | 反对耐普曼的积累 | **天平 + 一只手压下一端** | 器具（动作） | 暗褐 + 冷青 |
| A4 | 两种规律的斗争 | **两条绞在一起的曲线** | **抽象** | 明黄 + 深蓝 |
| E1 | 社会主义原始积累 | **从田野流向工厂的资源之流** | **回到实物（最大的一张）** | 暗金 + 铁灰 + 橙 |

**一条链的三个变化**：
1. **视点**：**记账（A1）→ 剪（A2）→ 压（A3）→ 缠绕（A4）→ 流动（E1）** —— 五个都是**动词**
2. **抽象度**：实物器具 ×3 → **抽象曲线 ×1** → 实物之流 ×1（**故意的节奏**）
3. **画面重心**：从**左下的谷堆**逐步移到**右上方的厂房**（与「从农村提取到工业」同向）
