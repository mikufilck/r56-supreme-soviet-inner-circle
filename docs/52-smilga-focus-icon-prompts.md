## 1. 要出的图（共 6 张）

> ⭐ **本批的特殊之处：他是一个「接线的人」—— 把散在各处的东西接起来、算清楚。**
> 所以整条线的视觉母题是 **「一张网与它上面的点」** ——
> **冰海上的航路 / 矿灯下的煤 / 一整面墙的方格网 / 长桌上的图表 / 地图上被搬动的工厂点 / 一道缝**。
> 📌 **入口图标的引导词早就定好了**（`docs/28` §83）：
> 「**经济图表 + 齿轮；拉脱维亚／里加的意象**」—— 本批与之同一套语言（经济 + 边境）。

### ⚠️ 整条线的视觉注意事项

1. **母题只有一件事：把散的东西对进格子里。** 本批的关键词是：
   **冰海航路 / 矿灯与煤 / 方格网 / 计算尺与挂图 / 图网上的圆点 / 一道缝**。
   与已完成批次明确区分开：

   | 批次 | 母题 |
   | --- | --- |
   | 李可夫（`docs/31`） | 工业、机构、供给线 |
   | 季诺维也夫（`docs/34`） | 国际、会场、东方人群 |
   | 加米涅夫（`docs/37`） | 手稿、档案、书与印刷 |
   | 斯米尔诺夫（`docs/40`） | 河、铁轨、雪原、界线 |
   | 谢列布里亚科夫（`docs/43`） | 营房、汇聚的线、道岔、公路、车床 |
   | 普列奥布拉任斯基（`docs/46`） | 账簿、秤与剪刀、统计曲线、从田野到工厂的资源流 |
   | 拉狄克（`docs/49`） | 越境的地图线、地下印刷品的墨、铁窗光影、街垒、课桌、一支笔 |
   | **斯米尔加（本批）** | **冰海航路、矿灯与煤、方格网、计算尺与挂图、图网上的圆点、一道缝** |

   🚩 **最容易混的三批 —— 本批的关键难点**：
   ① **与普列奥布拉任斯基那批（`docs/46`）—— 最危险的一个**：
      他那批是「**计量与提取**」（**账簿**、剪刀、天平、**统计曲线**）；
      本批是「**接线与铺开**」（**方格网**、煤、**点**）。
      ⭐ **一句话区分**：**他画的是「曲线」（连续的量），本批画的是「网格与点」（离散的位置）**。
      ⛔ **本批不要出现剪刀、天平、账簿、谷堆、河流**。
   ② **与拉狄克那批（`docs/49`）**：他的 A1 是**摊开的中欧地图 + 外伸的线路**（从一点**向外**伸出去）；
      本批是**覆盖全国的方格网**（把东西**对进**格子里）。
      ⭐ **区分**：**他是「从桌上送出去」，本批是「把东西收进格子」**。
      ⛔ **本批不要出现钢笔、报纸、传单、铁窗光影**。
   ③ **与谢列布里亚科夫那批（`docs/43`）**：他那批有「**汇聚的线**」与**道岔**（**铁路的实物**）；
      本批的线**不是铁路**，而是**图上的格线**（**在纸上**）。
      ⛔ **本批不要出现铁轨、道岔、站台、车床**。

2. **六张是一条「从海上到纸上、最后回到一道缝」的链**，顺序本身有意义：
   **冰海航路（1917） → 矿灯与煤（1921） → 一整面墙的方格网（1923） → 长桌上的图表（1924） → 图网上的圆点（1931） → 一道缝（结局）**。
   出图时请**按顺序看一遍**：**前两张是「实物与力气」，中间两张是「纸上的秩序」，第五张把纸上的东西搬回实物，第六张忽然跳到一个判断上** ——
   这个节奏是故意的（**他一生都在做前五张，第六张是他给这一切算的总账**）。

   ⭐ **首尾同轴的提示**：**A1 是「把边境的力量送进首都」，A5 是「把首都的工厂送到边境」** ——
   出图时 A1 与 A5 的**构图方向可以互为镜像**（A1 从画外向内、A5 从内向外）。

3. **E1 是结尾，构图应最饱满**（照前几批 E1 的处理）—— 它是全线的最后一个节点，
   **五个前置全完成**后才开。⭐ 它是**唯一一张抽象图**，其余五张都是实物。

4. 🚩 **画面里不要出现可辨认的文字或数字**（`docs/24` §1）——
   方格网、图表、挂图、黑板上可以有条纹、横格、色块与图例方框，但**不要写出可辨认的字母、汉字、具体数字或地名**。

5. ✅ **本批没有互斥项、没有成对图**（本线是单线）—— 6 张是一体的。

6. ⚠️ **不要画人脸、不要画人物肖像**（本批走苏联国策图标式）——
   需要「人」时用**手 / 背影 / 剪影 / 一排背影**，不要五官。

| A3 | 国家计划委员会 | **一整面墙的方格网 + 台灯** | **纸上的秩序（母题正主）** | 暗灰蓝 + 台灯绿 |
| A4 | 莫斯科国民经济学院 | **长桌 + 挂图 + 计算尺 + 几双手** | 纸上的秩序（器物） | 暖木 + 纸黄 |
| A5 | 生产力布局 | **图网 + 一只手搬动一个工厂点** | **把纸上的东西搬回实物** | 暗青灰 + 铁灰 |
| E1 | 弥合裂缝的人 | **同一张网 + 一道缝（上段缝合、下段裂开）** | **抽象（最大的一张）** | 土黄 + 暖白 + 深黑 |

**一条链的三个变化**：
1. **空间**：**海上（A1）→ 地下（A2）→ 一面墙（A3）→ 一张桌（A4）→ 一张图（A5）→ 一张更旧的图（E1）**
   —— 从**最开阔的海**，一路收到**桌面上的方寸**
2. **方向**：**A1 从外向内（把兵力送进来）→ A5 从内向外（把工厂送出去）** —— **镜像**
3. **时间**：**A1–A5 都是「他正在做」；E1 是「他回头看」** —— 前五张没有时间感，第六张有
