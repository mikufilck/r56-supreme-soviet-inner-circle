### 1.4 主干

> ⭐⭐ **主干 =「把舰队该有的东西，一件件从陆军那里拿回来」**
> ⭐ **一句话**：**别人在造船，他在造「部」。**

- **根 → 主干**的推导：根说「海军只是一个『局』」→ 那么「让海军不再只是一个局」就是逐件**把属于舰队的东西从陆军手里拿回来**（部 → 作战指挥 → 兵种 → 议事机关 → 对外宣示）。
- ⭐⭐ **首尾同轴**：**根 = 海军在公文里只是一个「局」（1926）；E1 = 海军是苏联自己的一个「部」（1937-12-30）。**
