## 1. 主干与推导

### 1.1 根 → 主干（详见 `docs/68` §2.1 / §2.2）

⭐⭐⭐ **根 =「一个手里只有一张汇率表的人」（1888–1917）**
⭐⭐⭐⭐ **主干 =「让一张印出来的纸，变成可以拿去算的钱」**

> ⭐ **一句话**：**别人在争「拿多少」，他在争「拿什么算数」。**

| 级 | 节点 | 从上一级推 |
| --- | --- | --- |
| 根 | 他会六种语言，在索邦读完法律与经济 | —— |
| ① | **银行国有化** | **第一件事：先把所有的账拿到手里** |
| ② | **突厥卢布** | **账拿到手里之后，第一件要换掉的是「不是钱的钱」** |
| ③ | **切尔沃涅茨** | **一小块地方换完了，该换全国** |
| ④ | **一美元值多少** | **换完了要能【对外】折算** |
| ⑤ | **国家资本主义** | **钱稳住了之后，他发现光稳钱不够** |
| E1 | **硬通货** | **这条路的全程，就是这一个书名**（用户 2026-09-20 把名字改短） |

⭐⭐ **首尾同轴**：**根是「他手里有一张汇率表」，E1 是「那张表上的东西变成了硬通货」。**

### 1.2 🚩 为什么主干**不**是「他做了苏联的货币改革」

- ❌ **「他做了货币改革」是结果，推不出五个节点的【层级】** —— 那句话把 A1/A2/A4/A5 都说没了
- ✅ **「让纸变成钱」能推出全部五级**，而且**每一级的产物都是一个「可以被拿去算」的东西**（判据 C 过）
- 🚩 **判据 B 自检**：**换一个同类职业的人来，这条轴成立吗？**
  → **李可夫管工业、普列奥布拉任斯基管理论、布哈林管农村** —— ❌ **换个人不成立** ✅
