#    · 吞并 = `annex_country = { target = FROM transfer_troops = yes }`
#      —— 原版 CHI_decisions.txt L2927 / BUL.txt L8899-9022 同款
#    · 特质过滤 = `NOT = { has_trait = X }`
#      —— 原版 common/scripted_effects/POL_scripted_effects.txt L369 逐字同款
#    · `every_scientist` —— R56 common/national_focus/australia.txt L3912 在用（无 DLC 保护）
#
#  ⚠️ 两个特质 id 都是【裸 id、没有 trait_ 前缀】，出处：

#     / `POL_sanation_right_leader = { type = all ... }`
